# SDL 概述

> 状态：草案。本文定义 SDL 的定位与规范范围，不确定具体实现方式。

## 定位

SDL（System Description Language，系统描述语言）是一种面向工程系统的声明式 DSL 和描述标准。

SDL 规定如何描述工程系统，texsys 负责处理 SDL 并支撑设计自动化运行。三者的关系是：

- **SysDA**：设计自动化方法论；
- **SDL**：系统描述语言与语义标准；
- **texsys**：SDL 的参考实现、一体化工具链与生态。

## 规范范围

SDL 规范包括：

1. 核心语义模型；
2. 声明式文本语法；
3. 类型、单位、身份与引用规则；
4. 组成、连接和空间描述；
5. 未知值、自由度、约束与设计承诺的语义；
6. 静态校验规则；
7. 模式版本、兼容与迁移规则；
8. 必要的标准化交换表示。

SDL 的关键目标不是只统一字段和文件格式，而是使不同符合规范的实现对同一份描述产生一致的对象身份、引用关系、单位、约束和未知状态解释。

## 非规范范围

以下内容由 texsys 或其他工具实现，不属于 SDL 核心标准：

- 评估器、求解器和综合算法的具体实现；
- 计算调度、缓存与 CI／CD；
- 包仓库、权限审批和平台运营；
- 图形界面与交互方式；
- 特定后端或原生软件适配器的实现。

SDL 可以为这些能力提供声明式契约，但不规定其内部算法和运行策略。
