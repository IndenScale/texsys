# 智能体面板设计系统

本文是 [DDR-0033](../../docs/ddr/0033-studio-agent-panel-qoder-redesign.md) 的落地规范，记录智能体面板的设计令牌、组件与状态。实现位于 `src/texsys/assets/studio/agent/`：令牌与组件样式在 `agent-ds.css`，组件在 `primitives.tsx`，面板组合在 `AgentPanel.tsx`。新增面板界面优先复用这里的组件，不在面板内另写一次性样式。

## 设计原则

1. **一屏只有一个重心。** 空态的重心是标语，对话态的重心是正文，输入区永远是第二重心。其他控件默认弱化，悬停或需要时才出现。
2. **控件说人话。** 触发器只显示当前值（如模型名），不加图标前缀和冗余后缀；没有第二个选项的选择器不显示。
3. **细节侧挂。** 说明与设置放在侧挂浮层，列表本身保持单行、等高。
4. **只显示真实数据。** 内核没有提供的属性（价格、上下文窗口、默认值标记）不显示、不推断。

### 字体与字号

字重不超过 500（工作台排版约束，由 `tools/check_studio_typography.mjs` 检查，因此不使用含变量的 `font` 简写）。正文字体沿用 `system-ui`，路径与命令使用 `--ag-mono`。

| 令牌             | 取值            | 用途                           |

| `--ag-font-hero` | `500 24px/32px` | 空态两行标语                   |

### 动效

浮层与侧挂卡淡入 `var(--motion-fast)`；标签切换、按钮状态不做位移动画。处理中只保留状态圆点脉动与工具旋转图标，遵守 `prefers-reduced-motion`。

## 可访问性

- 所有图标按钮提供 `aria-label`；标签栏使用 `role="tablist"`／`role="tab"` 与 `aria-selected`，左右方向键切换标签。
- 浮层使用 `role="dialog"` 或 `role="listbox"`，打开后焦点进入搜索框或第一项，关闭后焦点回到触发器。
- 颜色之外同时用图标表达状态（勾选、旋转、错误图标），对比度满足正文 4.5:1、图标 3:1。
- 浮层与工具栏标注 `translate="no"`，避免浏览器翻译扩展改写控件文字。
