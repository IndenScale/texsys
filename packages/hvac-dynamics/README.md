# 暖通水力与集总热动态能力包

本包提供定物性单相水的准稳态水力、集总热动态、工况求解及工程变更适配。具体设备实例、物理参数、控制信号、边界条件、需求与接受记录由项目声明。

## 能力与适用范围

支持管路沿程与局部损失、泵曲线与调速、阀门、反向流动、水及管壁蓄热、混合、热负荷、简化冷机和冷却塔。模型近似不因安装本包而变为厂家性能或现场测量事实。

SciPy 是明确的 Python 运行依赖。OpenModelica 适配器依赖外部 `omc` 配置，包同步不会安装该二进制工具。冷机固定 COP、泵固定效率和等效塔 UA 的适用限制仍然成立，不承诺完整节能调度性能。

## 包内独立参考

`tests/test_reference_physics.py` 保存可随包重跑的泵—阻力解析平衡、反向流动、全闭阀、Poiseuille 极限、集总冷却指数解及故意漏热反例。仓库测试直接复用这些定义，不维护第二套参考实现。

在消费项目中执行：

```bash
uv run --locked texsys package test hvac-dynamics -p 项目目录
```

pytest 与声明的 Python 运行依赖必须可用。包测试用于验证能力实现；项目工况及工程接受需要另行检查。
