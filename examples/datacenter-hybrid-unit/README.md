# 混合冷却数据中心概念单元

本例用于 40 MW 级单体建模能力开发。单元采用四台机柜和 400 kW IT 负荷，单体算例假设 4 层，每层 25 个单元。配电和冷却参数均为可替换的算例假设。

- `src/system.sdl.json` 描述 A/B 两路配电，以及各自的设施水 FWS、技术冷却回路 TCS 和精密空调供回风。供电连接顺序明确了负荷的优先路径。精密空调和 CDU 从锁定的 `hvac-equipment` 专业库导入，设备额定点由 SDL 行为参数提供。
- `src/unit.study.json` 记录机柜功率和重量、其他室内热量、水侧工况、房间环境条件及故障。断电会使相应冷却设备失效，液侧和空气侧分别检查可用容量。设计点的 CDU 能力受两侧流量温差、逼近温差和额定能力约束。多个 CDU 共用设施侧冷源时应用同一冷源容量上限。
- `src/cooling-equipment.study.json` 声明四台单元设备的放置原点。模块规格定义包络和端口位姿，供设施水支管和设备布局共同使用。
- `src/tcs.study.json` 声明两套技术冷却回路的泵曲线、分层管路和机房局部故障。机柜引用暖通库双回路模块，管路从 SDL 连接和已放置端口生成。
- `src/controls.sdl.json` 从锁定的控制库导入传感器、执行器和切换控制器，分别连接命令与反馈。`src/controls.study.json` 将控制点绑定到实际 TCS 管段、备用 CDU 和三层代表机柜，并声明故障与动作时序。
- `src/air-distribution.study.json` 声明精密空调 A/B 两路送风的截面、标高、管件阻力、回风格栅和机前检修空间。
- `src/air-environment.study.json` 声明冷通道、机柜进风方向、风机外静压上限、末端阻力系数、机柜风量、温湿度判据和局部故障。
- `src/floor.study.json` 通过轴线绑定结构跨和机柜位置，声明永久钢梁、临时支撑、阶段荷载组合、支脚验算参数和管线洞口需求。W 型模板截面默认值来自结构模块，项目可按选型覆盖。
- `src/slab-openings.study.json` 声明洞口与钢梁净距、竖井结构洞口相对预留边界的内缩量和屋面协调厚度。
- `src/frame.study.json` 声明整栋主框架轴网、主梁与横向系梁、柱、基础、跨外楼面和屋面设备区的重力荷载。
- `src/lateral.study.json` 在主框架轴网上指定纵横向交叉支撑，并声明风、地震矩阵、支撑退出及基础上拔敏感性工况。
- `src/diaphragm.study.json` 声明楼盖材料、屋面厚度、楼盖与钢梁的等效连接组刚度及各工况筛查限值。
- `src/foundation.study.json` 声明柱脚底板与锚杆、土体刚度和底面摩擦、沉降及基础截面限值。
- `src/foundation-ties.study.json` 声明支撑跨下的基础拉梁、有效刚度、水平土体刚度和方案筛查限值。
- `src/building.study.json` 声明楼层、单元排布及电气间、冷却设备间和竖井的占位。首期按 20 MW IT、满配按 40 MW IT 汇总，并声明共用进线、液侧排热能力和按实际管段标识注入的机房支路故障。
- `src/architecture.sdl.json` 引用建筑专业库的房间、墙、门洞、竖井和折返楼梯。`src/architecture.study.json` 声明分隔墙位置及厚度、门洞净尺寸、楼梯几何和出口位置。
- `src/fws.study.json` 声明楼级 A/B 设施水供回水干管、竖井、楼层总管、流量额定值、管段水力参数、并联泵组和漏液隔离联锁。楼级场景可注入管段或竖井失效、泵停用或转速受限、漏液、检测器失效和阀门卡开。
- `src/fws-branches.study.json` 声明楼层配水立面、干支管规格及需要连接的 CDU 供回水端口。每层几何沿用原水网与防火协调共同使用的楼层接口。
- `src/water.study.json` 声明湿干混合排热、原水、处理机组供电、初始及有效储水、共用排放能力和分时水源工况。
- `src/drainage.study.json` 将漏液场景接到排液支路、共用干管和集液预留，分别声明已隔离及隔离失败时的算例泄漏时长。
- `src/standby.study.json` 为单元 SDL 配电拓扑增加 A/B 外部市电、备用发电机群和本地 UPS 电池。声明各节点额定 kVA、各负荷功率因数、可用交流侧能量及切换时刻。
- `src/ride-through.study.json` 声明代表单元的三个热容节点、温度限值，以及精密空调、CDU 和共用设施水的重启延迟与恢复斜率。
- `src/protection.study.json` 为代表单元声明短路等效阻抗、电压基准、分断容量、保护时间带、逆变器限流值及对应的供电时段。
- `src/grounding.study.json` 将机柜和机房冷却设备绑定到单元等电位端子、楼层汇流排、两条接地干线与基础钢筋连接点，并声明独立的接头和钢筋导通数据。
- `src/fire.study.json` 声明机房与设备区分隔、设施水竖井围护、各楼层分隔要求、管线中心线定位及独立的封堵选择表。
- `src/egress.study.json` 声明机房和设备区人数、疏散通道、门和楼梯的防火要求，以及路线和通行能力的算例判据。门洞和楼梯的几何取自建筑模型。

```bash
uv run --locked texsys check -p examples/datacenter-hybrid-unit
uv run --locked texsys lock --check -p examples/datacenter-hybrid-unit
uv run --locked texsys build -p examples/datacenter-hybrid-unit
```

`build/datacenter/cooling-equipment.json` 记录 400 台精密空调及 CDU 的放置、支脚身份和端口坐标，并逐一核对 400 个 CDU 设施水供回水接口与支管端点。`cooling-equipment-layout.usda` 交付可独立打开的设备几何。精密空调的送回风和机前检修空间由下游气流布置报告校核。设备锚固、CDU 检修净距及电源实体路由仍待协调。设备容量、包络和安装质量均为方案假设。

`build/datacenter/tcs-study.json` 先按已有 FWS 分配校核逐机柜流量和冷量。当故障导致某个 CDU 无法用完已分配冷量时，联合求解以每条机柜回路的冷量为变量，在同一解中校核共用冷源、FWS 管段与泵扬程、CDU 热量平衡，以及 TCS 管路、机柜流量和泵扬程。求解先提高整栋实际送达的冷量，再在水力条件允许时尽量保留原分配。报告以 `building_scenario` 追溯基线，在 `dispatch.joint_fws` 记录新分配、压力余量、故障与隔离记录，以及逐 CDU 热量平衡误差。

TCS 按实际中心线长度、管径、泵曲线、机柜歧管、快接和等效冷板阻力计算。报告列出供回液工况、各部件压降、最不利回路和缺冷机柜。`tcs-layout.usda` 交付 400 台机柜、4,400 条管路记录，并核对 1,600 个机柜端口和 400 个 CDU 端口。布置检查包括 TCS 管间净距、机房包络和邻近 FWS 管路净距。

正常和 A 路失电工况均交付 30 MW 液侧冷量。单个机柜 A 路支管失效后，B 路向该机柜补足 75 kW。如果同一机房的 B 路 FWS 回水也被切断，只有这台机柜缺冷 75 kW。单个机房两台 TCS 泵分别限速至 50% 时，双路分担后仍满足 300 kW。分别限速至 35% 时，该机房四台机柜合计缺冷约 93.7 kW。A 路失电、B 路 FWS 泵限速和一个机房 B 路 TCS 泵限速叠加时，整栋约可交付 26.31 MW，两侧最不利回路均达到泵扬程约束。

模型采用固定温差的稳态配流和厂家待核实的双独立回路。楼层内故障状态与供液可达性相同的机房按相同机柜位置等量分配，FWS 扬程校核覆盖组内实际管路。机柜侧将同一路内的服务器并联支路合并为等效阻力。设备实际曲线、水力瞬态和其他机电净距留待深化。 [OCP 冷板液冷参考](https://www.opencompute.org/projects/cooling-environments/cold-plate/)

`build/datacenter/controls-study.json` 记录漏液、关阀命令、实际阀位、反馈时间与质量、备用启动、流量证明和锁定。联锁只使用新鲜反馈。两只阀确认关闭后才发出备用启动命令，并用联合水力计算的机柜支路流量验证备用回路。热模型按故障前、隔离中、已隔离和已转供的水力状态求解三层 Rack-04 的温度，输出温峰、越限时长、恢复时间和能量平衡。

快切算例在漏液后 8 秒取得备用流量证明，14 秒恢复 75 kW，机柜固体等效温峰约 57.3 °C。检测延迟 60 秒时，水力接管仍成功，机柜固体等效温峰约 72.7 °C，超过 64 °C 的算例判据。回水阀卡滞或闭合反馈过期时，备用启动被禁止。备用 FWS 路径失效或流量开关无反馈时，启动证明超时并撤销备用命令。证明在转供后丢失时也会撤销命令。

控制研究采用项目假设的传感器延迟、阀门行程和复启斜率，以稳态水力点作为时序边界。复启前按尚未证实的供冷能力处理，复启阶段按声明斜率插值。机柜使用局部等效热容及按负荷分配的空气侧能力，结果用于校核模型中的动作与温升。整机房气流耦合、真实点位协议、现场整定和调试证据仍待补充。

`build/datacenter/air-distribution.json` 和 `air-distribution-layout.usda` 交付 200 台精密空调的顶送风管、400 只冷通道送风箱、热区回风格栅和机前检修包络。每只风箱服务一对相向机柜，出风点追溯到对应的 SDL 连接。布置校核核对 400 个机组送回风端口，并检查 A/B 管路、钢柱、楼盖梁底预留、设备及 FWS、TCS 管路净距。

`build/datacenter/air-environment.json` 使用机柜显热、供电状态和实体风路，逐台校核 400 台机柜的进风。风机静压分配到共用管段、格栅、成对支路和末端开口。报告记录压降、风速、送风捕获、回流、旁通、进排风温度、相对湿度、冷表面露点裕量和显热平衡。三维产物在同一坐标系定位冷通道、机柜和热点。

满配正常时最高进风约 24.32 °C，A 路失电后约 24.95 °C，单台精密空调停机时约 25.02 °C。三层单个机房 Rack-04 的两路送风支路被阻断后，房间混合回风约 28.14 °C，机柜进风达到约 34.56 °C。围护回流敏感性工况的控制机柜约 29.02 °C。局部露点升至 21 °C 时，20 °C 冷表面出现负露点裕量。

模型采用固定机柜风量、混合热区和给定水汽分压。满配时 A 路达到假设的 750 Pa 静压上限，B 路约 736 Pa，最高管段风速约 34 m/s。通过布置与机柜进风筛查只说明满足所列算例判据。厂家风机曲线、末端风速和噪声、潜热与渗透负荷、机柜进风垂向梯度及现场调试仍待核实。 [ASHRAE 数据中心气流与热管理建议](https://www.ashrae.org/technical-resources/topics-and-initiatives/ai-data-center/energy-and-thermal-efficiency)

`src/floor.sdl.json` 从锁定的结构库引用 W 型永久钢模板现浇楼板。模块包提供截面默认值、二维示意和分体几何样件。项目楼板跨沿机房进深延伸到 8 m，覆盖机柜、CDU 和精密空调。`build/datacenter/floor-study.json` 给出材料用量及浇筑和使用阶段校核。浇筑阶段将湿混凝土、施工面荷载和施工集中荷载施加给钢模板。使用阶段由钢筋混凝土单独承载，四台机柜和四台冷却设备的安装重量分配到各自的支脚。

各条带按独立简支跨计算弯矩、剪力、挠度及支承反力。条带反力在宽度中点传给横向钢梁，钢梁自重由截面尺寸计算。3 m 无撑浇筑跨弯矩和挠度超限，加设临时支撑后，最长 1.5 m 的浇筑跨通过所列校核。设备支脚另按设定接触面积和有效深度筛查局部承压及直接冲切，遇到楼板边缘、洞口或相邻支脚控制周边重叠时转入构造复核。

`deck-slab.usda` 分体表达钢模板和现浇板，钢板厚度按截面的竖向偏移近似。`floor-assembly.usda` 同时交付模板、楼板和四道永久钢梁，定位与反力报告一致。洞口按提资矩形定位到受影响的条带、跨段和支承线，整体计算采用完整条带和刚性支座。洞口补强、机柜支脚局部验算、冷却设备锚固、模板局部稳定和积浆、支撑连接、裂缝和振动仍需深化。荷载系数、刚度和限值均为算例输入。 [美国钢楼承板协会楼承板设计手册](https://sdi.org/wp-content/uploads/2024/03/FDDM2-072623.pdf)

`build/datacenter/slab-openings.json` 将防火报告中的 14 处楼板贯穿绑定到实际结构标高和宿主，其中 12 处设施水套管位于竖井封闭板，2 处排液管套管直接穿主楼板。竖井洞口从主楼盖扣除，内部套管只从封闭板扣除。报告同时校核洞口与主梁、系梁及机房次梁的平面净距，以及套管与实际宿主边界的距离。

楼层设施水采用同层上走管，因此 100 个机房穿板预留从主楼板切口清单撤销。`slab-openings-layout.usda` 交付带切口的主楼板及独立竖井封闭板，圆套管以外接矩形表达结构净空。备选穿板构造仍由 `deck-openings-detail.usda` 交付。该模板移位后距最近系梁 140 mm，报告列有采用备选构造时的材料扣减量。封闭板支承、洞边补强与施工方法仍需专业深化。 [美国钢楼承板协会楼承板开洞说明](https://sdi.org/wp-content/uploads/2024/03/FDDM2-072623.pdf)

`build/datacenter/frame-study.json` 将 100 个机房结构跨的次梁端反力落到主梁轴线，并按分担宽度把跨外楼面和设备区压力转为主梁分段线荷载。冷却设备荷载从支脚追踪到钢梁端、钢柱及各基础，另行核对平衡。首期保留全楼和屋面自重，三、四层采用未安装机柜和机房冷却设备的结构跨反力。满配再加载这两层设备。

算例采用 700 mm 深主梁、410 mm 深钢柱截面以及 3.2 m × 5.0 m 的基础底面。满配使用组合的柱底反力合计约 102.71 MN，其中机房冷却设备约 2.354 MN。设备区侧 XS/Y4 基础平均压力约 194.3 kPa。采用 210 kPa 的算例承压限值时，所列重力筛查通过。将该限值降至 90 kPa 的敏感性工况会触发基础超限。`frame-layout.usda` 交付主梁、系梁、机房次梁、钢柱、基础包络和实例化机房楼板，楼板顶面与设备安装标高对齐。

主梁按独立简支跨、钢柱按轴力累积，主框架报告采用基础平均压力。跨度、额定承载、荷载组合和地基限值均为算例输入。结构深化仍需校核梁柱节点、浇筑期支撑传力，并协调地勘和现场边界。 [住房和城乡建设部《钢结构通用规范》公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_761191.html)

`build/datacenter/lateral-study.json` 在南北侧配置 6 道 X 向支撑，在东西侧配置 4 道 Y 向支撑。各跨沿相同轴线从基础连续到屋面，并避开疏散报告中的门洞。刚性楼盖模型按层分配水平剪力和扭矩，逐基础记录水平力、倾覆轴力和叠加重力后的承压与净上拔，核对整体平衡。`lateral-layout.usda` 交付与主框架共坐标的支撑杆件包络。
