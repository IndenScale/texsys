# 风冷机房

本项目把轴网、钢结构、架空防静电地板、统一规格机柜和下送风冷却系统落在同一个可构建示例中。房间为 12.0 m × 8.4 m，按 L01 楼层坐标建模，原点为 A/1 轴交点，结构楼板为 ±0.000 m，架空地板完成面为 +0.450 m。

| 对象         | 示例配置                                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 轴网和钢结构 | A–C × 1–3，主轴距 6.0 m × 4.2 m。六根 H 形钢柱、七根工字形钢梁，梁顶 +4.200 m                                                             |
| 架空地板     | 600 mm × 600 mm 模数，256 块防静电 HPL 饰面钢质板、16 块冷通道送风板、313 个支座，两处机组下送风开口各占四个模数                          |
| 机柜         | 统一采用 42U、19 英寸安装体系，外包络 600 mm × 1200 mm × 2000 mm，两排共 16 台，正面相向                                                  |
| 冷却         | 两台下送风冷却单元，按每台 60 kW 显冷量和 4.5 m³/s 名义风量建模。空气经地板下静压箱和送风板进入冷通道，再穿过机柜至热通道，经机房上部回风 |
| 空间         | 冷通道和两条热通道净宽均为 1.2 m，东侧设 1.2 m 开口                                                                                       |

模型为方案级。尺寸、材料、负荷、额定能力与验收阈值均为项目假设。钢梁柱使用参数化截面，机柜、墙体和地板为方案布置几何。USD 用南、西两侧剖切墙展示内部空间。

## 源文件

- [系统与风路](src/system.sdl.json)记录设备身份、端口和送回风网络。
- [42U 机柜模块](src/library/modules/rack-42u/module.toml)提供 16 台实例共用的机柜定义、接口几何和单位负荷模型。
- [轴网、分区与布置](src/room.layout.json)记录坐标、构件截面、地板模数、设备定位和设计净宽。
- [空气侧设计依据](assets/air-design-basis.json)记录供回风温度、附加热负荷、空气物性及正常和单机退出场景。

两排机柜的起点引用 `B/2` 轴交点并各自声明偏移。梁柱由结构库根据命名轴线、结构楼板及梁顶基准生成。通道边界继续由项目显式给定，移动轴线后会重新检查机柜与通道的匹配关系。 [空间与结构标准库](../../packages/README.md#空间基础库与结构专业库)

## 模块库

在 Tex Studio 的部件库中打开本项目，或从另一个项目添加本示例根目录作为版本化库来源。钢构和钢筋混凝土构造来自独立的 `packages/structure` 目录，也可单独添加。每个模块的 `module.toml` 声明 SDL 入口、规格数据、可单独打开的 USD 几何、SVG 符号和端口绑定。 [模块包约定](../../spec/sdl/04-module-package.md) · [结构库目录](../../packages/README.md#钢筋混凝土典型构造)

| 类别             | 模块                                                               |
| ---------------- | ------------------------------------------------------------------ |
| 结构库           | 钢结构支架、直条钢筋、钢筋混凝土墙、板、梁、柱、独立基础和设备基座 |
| 架空地板与支吊架 | 防静电地板、送风板、地板支座、吊杆、支吊架                         |
| 机柜与设备       | 42U 机柜、机架式 PDU、交换机、服务器、下送风冷却机组               |
| 线缆             | 单模光纤跳线、RJ45 超六类跳线                                      |

房间 SDL 额外声明两柜的样例安装、配电、光纤上联和铜缆管理链路。`room.layout.json` 记录设备 U 位和线缆路由经过点。线缆端点由设备模块的端口位姿推导。构建校验机架 U 位冲突、设备包络和路由端口对应。路径长度供方案比较，施工放线、弯曲半径和碰撞仍需按选定线缆及实际路由复核。

## 重建与查看

从仓库根目录运行：

```bash
uv run --locked texsys check -p examples/hvac-air-cooled-room
uv run --locked texsys lock --check -p examples/hvac-air-cooled-room
uv run --locked texsys build -p examples/hvac-air-cooled-room
```

构建目标为 `hvac:air-room`，输出位于 `build/hvac/air-room/`。

- `room.usda` 是以米为单位、Z 轴向上的三维场景。轴线、钢构、地板板块、支座、机柜、冷却单元和分区保留独立对象，可在 USD 工具中展开检查。
- `module-library.usda` 集中展示 12 个本地模块和锁定的 8 个结构库模块的三维几何，各对象保留对应的 SDL 入口和模块版本。
- `floor-plan.svg` 标注轴网、设备编号、冷热通道、排风方向和机房入口。
- `checks.json` 汇总数量、设备包络和通道检查、SDL 风路完整性及三种工况的风量和显冷量预算。构建证据另见 `build/build.json`。

每柜 3 kW、附加热负荷 2 kW 时，计算总热负荷 50 kW。按送风 22 °C、回风 32 °C，所需风量约 4.14 m³/s。16 块送风板的名义风量合计 4.48 m³/s，任一冷却单元退出时仍有 60 kW 名义显冷量和 4.5 m³/s 名义送风能力。该检查采用房间级热平衡和额定量比较。实际配风、静压损失、机柜进风温度、结构承载及地板防静电性能须分别复核。
