## 问题详情

### OQ-3

根部件的显式 Net 已有成员引用、唯一归属和介质一致性校验，见 [JSON 交换子集 v2](../spec/sdl/02-json-exchange.md#显式网络v2)。匿名推导与跨层级成员一致性仍需定义。

### OQ-4

精度可接受不等于无需声明。需要确定：每个评价器声明输入需求、适用范围、模型假设、误差量级与失效条件，并规定证据强度的分级方式。

### OQ-5

ADR-0001 已指出该映射是必要产物。身份若绑定到可变路径，缓存与追溯立即失效；若完全脱离路径，则需要额外的稳定标识机制。ADR-0002 进一步把身份稳定性变成硬要求。

### OQ-6

ADR-0001 的生效前置条件。最小 spike 应覆盖：B-rep 创建、布尔、测量、三角化、USD 往返、跨平台一致性与失败状态可见性。

### OQ-7

当前倾向于：暖通专有概念（介质、风量、结露判据）走领域扩展；通用概念（Component、Port、Connection、Placement）留在核心。

### OQ-8

原属 MEMO 的"待进一步对齐"条目，现已全部迁入本表。

### OQ-9

见《设计自动化原理》第十三章对追溯与复现的要求。

### OQ-10

不影响当前实现，但影响对外文档与仓库命名。

### OQ-11

已决，转 [ADR-0017](adr/0017-schematic-projection-symbol-resolution-and-rendering.md)。人工位置和样式进入版本化 overlay，专业事实回到 SDL，专业注记与现场确认进入有所有者、来源和状态的显式注记契约。overlay 仅覆盖白名单排版字段；引用失效或冲突必须诊断。第一版 draw.io 只导出、不回读，重新生成不得覆盖有效人工排版、人工事实或专业注记。

### OQ-12

ADR-0002 要求"设计模型可被调度消费"。最小可检验形式可能是：一份稳定的可寻址对象清单 + 能力参数 + 连接拓扑导出。是否需要版本化快照、单位与状态语义，待定。

### OQ-13

已决，转 [ADR-0017](adr/0017-schematic-projection-symbol-resolution-and-rendering.md)。缺 Placement 不阻塞纯连接视图，允许生成显式标记的 `connectivity-only` 产物。已有身份、介质、流向和关键参数标注保留；空间标注只有存在模型依据时才输出，图面坐标不得回写为物理位置。

### OQ-14

[ADR-0019](adr/0019-first-executable-hvac-schematic-slice.md) 明确首版仅支持单页根网络叶子实例。完整 ADR-0017 的递归展开／折叠、跨页 occurrence、分组和注记所有权仍需版本化交换模式与守恒反例；在此之前明确拒绝相关输入，不能展平成丢端口的图。

### OQ-15

首版固定布局输入、ELK 版本／摘要、数值精度与保守字符框，但使用主机 monospace 字形。需确定可分发字体许可与摘要、真实字形度量、标签／线线碰撞规则和跨主机渲染基线。没有这些证据，不将同环境的字节一致性扩展为跨平台视觉一致性。

### OQ-16

[ADR-0021](adr/0021-tex-studio-plugin-based-disciplinary-workbenches.md) 已接受插件式多专业工作台架构。需要定义插件／专业清单模式、命名空间与入口注册、宿主兼容和依赖解析、加载／切换／退出生命周期、公共操作约定、访问范围，以及 Electron／Web 能力发现与适配。需明确已有 Python 领域包和 Studio UI 插件的声明关系，并以工程专业和管理／商务类专业验证同等接入。

首个本地 Web 子集已由 [工作台契约 v1](../spec/studio/01-workbench.md) 定义，采用独立的 `texsys.studio` entry point、显式前端入口和 API 版本。完整 Electron／Web SDK、管理／商务类工作台与分发兼容仍保持开放，不把 HVAC 首个切片视作全部接入验收。

### OQ-17

[ADR-0021](adr/0021-tex-studio-plugin-based-disciplinary-workbenches.md) 要求专业计算与协同遵循共同契约。需要定义任务输入快照、运行身份、状态、日志、取消与重连、结果变量／对象关联及旧结果标记；明确本地与远程执行的宿主适配。提资部分沿用 ADR-0012，补充要求、固定发布版本、逐接收方处理结论、下游采用关系及变更影响的交换模式。这些协议不代替 OQ-9 对证据与审批通用归属的决策。

[工作台契约 v1](../spec/studio/01-workbench.md) 已定义本地输入副本、后台进程、持久运行记录、取消、结果修订与历史状态。远程执行、完整跨专业提资与采用关系尚未实现，本问题继续开放。
