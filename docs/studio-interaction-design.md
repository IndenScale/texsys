# 工作台空间与动效准则

日期：2026-11-06。

## 稳定入口与区域归属

Activity Bar 是常驻导航，独立于可收起的资源面板。竖向排列，方向键上下切换；点击某个 Activity 展开对应内容，同一时刻只有一个 Activity 内容区域。标题栏 Left Panel 按钮只控制资源面板内容，不隐藏 Activity Bar。

标题栏已有直接入口的布局操作不占据统一搜索的空查询列表。搜索“布局”“侧栏”“资源面板”等关键词时仍可检索和执行，菜单命令 ID、快捷键及可用状态保持一致。

## 空间变化保持连续

改变区域尺寸、层级或控件形态的操作使用连续过渡。布局默认 200 ms，颜色和透明度反馈默认 110 ms，标题 Hover 的横向伸缩为 380 ms，项目名文字交接为 160 ms，统一采用先快后慢的缓动。运行中再次操作从当前呈现状态反向，不等待上一段动画完成。

面板开闭连续改变可见尺寸，收回过程结束前保留内容。标题与输入在同一固定命中区内交接；Hover 外框以中心为锚点横向变宽与收窄，高度和纵向位置不变，采用 cubic-bezier(0.4, 0, 0.2, 1) 的先加速后减速曲线。Hanging 列表从输入下沿展开及收回。状态栏菜单、工具提示和通知在退出期间保留呈现内容，但立即停止接收输入并退出辅助技术的交互树。

拖动、画布平移等直接操作必须跟手，不设置缓动追赶鼠标。内容和候选结果更新不播放位移动画，不给每个对象添加装饰性运动。系统开启“减少动态效果”时关闭非必要过渡。

## 面板调整不改变图纸相机

图纸首次显示和用户主动点击“适合图面”时计算适配宽度。面板开闭、连续拖动及窗口尺寸变化只改变观察范围，不重新适配图纸、不重置缩放和平移。

保留图纸在屏幕中的锚点和图元像素尺寸。左侧区域改变时补偿画布原点移动，右侧与底部区域变化只增加或裁减可视范围。平移、缩放、对象定位与主动适配属于明确的相机操作。

## 收起边缘仍可操作

左、右、底部面板关闭后保留 1 px 边界和 6 px 拖动命中区，支持鼠标拖动、键盘调整及双击恢复默认尺寸。资源面板的恢复边缘位于 Activity Bar 右侧。

关闭保留上次可用尺寸；重新点击标题栏布局按钮恢复该尺寸。内容、滚动状态和未提交草稿不因开闭被卸载。关闭区域停止接受键盘焦点。

边缘拖动使用吸附与滞回。进入关闭吸附区时预览完全收起；必须拉过更远的展开阈值才解除吸附，避免在临界位置反复切换。桌面侧栏关闭阈值为 48 px，展开阈值为 72 px；较小面板按最小尺寸收窄阈值。释放后停在完全关闭或最小可用尺寸及以上，不保留不可用的窄缝。拖动期间通过边界加深提示吸附位置；取消拖动恢复原状态。

一次拖动的最终尺寸与可见状态必须原子提交。分隔线随布局移动时，即使指针捕获丢失，也必须继续接收窗口级移动与松手事件；窗口失焦、Pointer Cancel 或 Esc 则取消并恢复原状态。不能把捕获丢失直接等同于取消，让用户重复执行才生效。

## 验收方式

- 对比开闭及拖动前后同一设备的屏幕坐标和宽高，允许的差异仅为浮点舍入。
- 折叠全部内容面板后仍能使用五个 Activity 入口和三个恢复把手。
- 在吸附区附近往返拖动，关闭与展开状态不反复跳变；释放、取消与重新展开均有明确结果。
- 验证搜索入口宽度、焦点、关闭过渡及减少动态效果，确保动画不改变操作结果。
