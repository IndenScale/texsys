# Tex Studio 与 HVAC 工作台实施记录

本文记录 2026-11-06 首轮实现及本地验证。现行接入协议见[工作台契约 v1](../spec/studio/01-workbench.md)，macOS 上的启动与维护见[常驻开发容器](development-container.md)。

## 实现结构

- `src/texsys/studio/`：专业发现、项目输入修订、隔离执行副本、后台进程、持久任务记录和本地 HTTP API；不导入暖通专业。
- `src/texsys/assets/studio/`：共享前端 SDK、Studio 宿主、专业切换、任务抽屉与公共样式。
- `packages/studio-hvac/`：通过 `texsys.studio` 注册的暖通专业插件，自行定义导航、设备与器件视图、参数编辑、检查和仿真；复用已有工程图元与领域 API。
- `tests/test_studio.py`：13 项后台契约回归；CI 增加宿主与专业工作台的 TypeScript strict 检查。

## 首轮验证的操作路径

从“系统设计”生成系统图和原理图；从“设备与参数”或图面选择实例，在右侧编辑完整参数绑定。保存形成实例覆盖，恢复继承和撤销仍执行源修订检查。外部编辑造成基准变化时，保留表单并报告冲突。

“仿真分析”可运行单工况或全部工况，通过 SciPy 或已配置的外部 OpenModelica 执行。后台任务使用提交时的源输入副本，任务与结果保存在项目 `build/studio/jobs/`。外部后端缺失时明确报告，不切换后端冒充执行。Studio 的“动态仿真”调用现有行为 `evaluate` API，不改变 ADR-0010 对几何 `sim(event)`／`sim(field)` 的分类。

## 本地验证

最终工作区 Python 全量 **156 passed**，其中 Studio 契约回归 13 项；Node 工程图元与命令规则共 13 项通过；共享图元、Studio 宿主与 HVAC 工作台的 TypeScript strict 检查通过；全仓库 Markdown 与 Prettier 检查通过。设计示例锁文件已随共享回放组件变化更新，动态冷站 lint 与设计锁检查通过。本轮没有远端 CI 或 Electron 运行证据。

浏览器验证使用实际 `hvac-dynamic-station` 项目，确认专业菜单仅列出已加载 HVAC；图纸构建真实运行，模型实例为 8 个、连接为 9 条。泵扬程由 22 m 保存为 23 m 的实例覆盖，源修订与旧结果状态随之变化；通过 GUI 撤销后恢复 22 m 的继承绑定，示例源文件没有残留修改。

实际从 GUI 启动全部三个 SciPy 工况：负荷阶跃 pass、泵速调整 pass、停泵 fail。任务显示“执行完成”，独立工程结论显示“未满足”。结果可以切换工况／后端，事件跳至 300 s，曲线、时间游标、设备选择与约束报告关联。

浏览器截图位于本机忽略目录 `build/evidence/studio/`：`system.png` 为桌面系统设计、`simulation.png` 为停泵失效结果、`mobile.png` 为 390 px 窄屏设备表。窄屏导航保持可见，页面宽度未超出视口；验证结束后恢复桌面视口。它们与自动测试分别证明交互行为和后台契约，不代表真实工程参数、厂家标定或正式提资已验收。

## 首轮实现的边界

2026-11-06 第一轮信息架构与交互改造将入口调整为项目概览、设计文档、工况与结果、检查与问题、成果与导出，并增加独立的类型选择、参数草稿保护、显式结果叠加、约束定位和集中成果导出。[界面改造记录](ddr/0001-hvac-workbench-interface-round1.md)

当时仅实现 HVAC 专业工作台，项目管理桩用于专业发现测试。器件库显示模型定义与共享图元，图元比例预览不改变性能或物理尺寸，模型源视图为只读。架构搜索、物理布局布线、拓扑编辑、器件类型创建和正式提资尚未接入。Electron、远程账户、远程执行和跨专业接入列入 OQ-16、OQ-17。
