# ADR-0027：增量构建、分支失败隔离与只读项目预览

- 状态：已接受
- 日期：2026-11-11
- 修订：ADR-0011 的产物状态与执行策略，补充 ADR-0013、ADR-0021、ADR-0026

## 决策

`build` 执行项目显式选择的目标及其依赖，生成 BOM、拓扑、原理图、空间场景和检查结果。独立分支在其他分支失败时继续执行；被失败前置条件阻断的目标记录原因。必需检查不满足、无法判定或执行错误仍使本次构建返回非零，不能将尽力生成等同于构建通过。

分别记录目标是否执行、复用缓存或被阻断，工程判定，以及产物是否完整、是否对应当前输入。完整的失败检查报告和对应设计场景可以展示；不再仅因工程判定不满足便把全部产物解释为结构残缺。不可读取的清单、失效的依赖锁及不安全路径不能靠部分预览绕过。

目标状态只证明所选契约。编译与投影成功不表示物理判据满足，通用预览使用“目标判定／通过”表述，实际工程结论留在有明确适用范围的检查报告中。

构建缓存按目标身份、实现与运行环境、配置、声明输入及上游产物摘要建立。未声明细粒度输入时使用保守输入集。命中缓存前校验内容，恢复缺失输出；损坏缓存重新执行。不能可靠固定输入的外部钩子不复用缓存。完整且可重现的工程不满足结果允许复用，进程异常或输入执行中变化不能登记为成功缓存。

每次构建保存独立运行清单和产物快照，最新清单仅作为入口。原始输出路径与快照身份分别保留；查看历史产物不能误读被后续构建覆盖的同名文件。部分生成、来源失效和旧版本回退必须显式显示。

Tex Studio 在现有中央文档区提供项目预览，复用项目根与实例导航。预览从构建清单选择产物，不按文件修改时间猜测项目主场景。工程包生成带身份和来源的数据，IDE 负责渲染、选择对象与定位源码，不通过预览器安装项目依赖或运行另一套物理实现。

## 只读与未来编辑

首期预览只读：旋转、缩放、切换产物、选择对象与打开源码不修改声明式设计。产物保留根对象、实例身份、图元身份和 source map，为后续编辑提供可定位的来源。本决策不预先实现反向写回或把派生产物提升为事实源；将来写回须另行定义明确的源操作和一致性校验。

## 验收

同一实际项目首次构建生成预览产物；重复构建命中缓存；局部输入变化使相关目标重算并复用无关目标；一个分支失败仍可查看其他有效产物。通过第二个相近案例检查复用边界。验证缓存损坏、产物删除、输入漂移、失败及缺失结果；Chrome 中验证项目预览、对象定位、过期提示和重建刷新。

项目预览不证明真实设备已校准、任意领域图纸均可生成或整个运行环境已完整复现。DevOps 合并门禁与消息通知继续按 ADR-0026 保持在本期范围之外。
