# ADR-0022：区分项目检查与源文件风格检查

- 状态：已接受
- 日期：2026-11-09
- 取代：[ADR-0007](0007-formal-checking-and-formatting.md) 中 `lint` 作为项目检查命令的约定
- 被取代：无

## 背景

原 `lint` 命令实际执行项目检查，名称容易被理解为风格检查。团队需要分别运行两类检查，并从命令和 API 名称判断各自报告什么。

## 决策

1. `texsys check` 和 `texsys.api.check` 汇总项目结构、解析、模型校验与专业检查。领域包通过 `TexsysPackage.check()` 提交诊断。
2. `texsys lint` 和 `texsys.api.lint` 检查 SDL 源文件风格。首版沿用既有规范 JSON 表示，`format` 负责将源文件整理成这种表示。
3. 仓库调用方直接改用符合职责的入口。两个命令拥有独立语义。

## 验证与复审

回归测试应分别覆盖风格不合规的有效模型、格式规范的无效模型，以及无法解析的输入。当前诊断与退出码见 [SDL 交换契约](../../spec/sdl/02-json-exchange.md#诊断与格式化)。当独立解析或模型校验产生单独的调用需求时，再评估 CLI 子命令。
