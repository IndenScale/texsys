# ADR-0033：在图页中保留工程比例

- 状态：已接受
- 日期：2026-11-15
- 补充：[ADR-0030](0030-independent-sheet-components-and-content.md) 的视图适配

## 决策

图页仍以毫米为纸面单位。项目可为视图显式声明 `1:N`。上游 SVG 须声明 `data-coordinate-unit="m"` 与正的 `data-units-per-meter`。编译器按这两项把视图宽高换算成纸面尺寸，并在模板内容区内居中。视图超出内容区时，构建以错误结束。图页有多个视图时使用同一比例，标题栏的比例必须与视图声明一致。来源报告保存视图坐标框、工程比例及纸面位置和尺寸。

原理图及示意仍可使用 `fit`，标题栏继续标记 NTS。校准比例来自项目选择和上游坐标声明。校准图纸使用原尺寸打印。纸面版式、工程描述和专业审查沿用既有分工。

## 验证

以 AIDC 图页检查校准视图实际纸面宽高，检查越界或缺失单位时报错。复跑既有原理图和总说明，核对 `fit` 与纯文字图页可继续编译。
