# ADR-0028：独立文件文档与预览渲染契约

- 状态：已接受
- 日期：2026-11-11
- 修订：ADR-0027 的 Studio 预览入口、文件编辑与内容读取契约
- 交互决策：[DDR-0012](../ddr/0012-studio-file-preview-and-source.md)

## 问题

原理图、拓扑、BOM 和场景已有实际文件，但 Studio 曾隐藏构建目录并将产物挂在项目实例根对象的子视图中。后续文件入口又把生成物强制只读，并用历史产物身份支配普通文件的显示方式。这些行为使通用文件组件与专业渲染耦合。

## 决策

文件文档以真实项目相对路径为身份，文件资源管理器、快速打开、标签切换及关闭重开共享同一文档模型。构建目录中的公开文件使用普通文件读写接口；运行快照、依赖缓存、Studio 中间存储及版本库内部目录保持隔离。公开文件的可发现性不依赖构建清单，否则新建或重命名后会消失。

源代码、文件版本和未保存内容由通用编辑器管理。预览实现根据文件格式接收当前内容，在统一文件组件的预览区域渲染；预览元数据仅描述格式与可用源映射，不改变编辑权限或组件布局。普通 JSON 不使用专用报告或 BOM 页面。Markdown、图纸和场景复用统一的「预览 / 源代码」切换，交互细则见 DDR-0012。

当前文件读取与不可变构建记录分开。版本、目标判定、完整性和来源仍保存在构建记录中，但文件预览不能默默替换为旧快照，也不以构建摘要匹配作为编辑或预览实际文件的前提。读取失败显示当前文件错误，不切换到其他同类产物。所有异步文件读取共享按路径的请求身份，旧响应不能覆盖新内容。

文件编辑、保存、重命名、删除与替换使用通用版本校验；自动刷新保留未保存编辑。修改生成文件只改变该文件，后续 build 可按设计源重新生成。图形交互暂不反向写回声明式设计；未来图形编辑另行扩展源操作契约。

对象文档保留模型属性和部件引用，删除产物子标签与虚拟“交付物”节点。底层增量构建、不可变历史记录和失败状态继续遵循 ADR-0027。

## 验收

普通文件和构建公开文件均可独立打开、编辑、保存与重新发现；私有存储不能通过文件接口修改。原理图与 Markdown 在同一文件组件内切换预览和源代码，普通 JSON 直接编辑。当前文件变化与未保存编辑进入相应预览，旧异步响应和历史快照不得替换新内容。运行状态和缓存信息不占据文件组件布局。
