# ADR-0019：以单页根网络启动 HVAC 原理图可执行切片

- 状态：已接受
- 日期：2026-11-05
- 取代：无
- 补充：ADR-0017、ADR-0018

## 背景

进度审查发现：设备、端口与 Connection JSON、BOM、USD 包络和简化行为断言已有可执行实现，但系统图／原理图只有决策文档；连接 JSON 不能代表已经具备出图能力。ADR-0017 的完整目标还涉及分组、跨页、符号目录、编辑与复杂排版，需要明确首个可交付代码子集，避免将全部设计承诺等同于已实现。

## 决策

1. 沿用 `hvac:system-schematic`，落地通用 `texsys-diagram`、本地 `texsys-diagram-elk`、专业 `texsys-hvac-diagram` 三包，通过数据契约组合。SVG 与非压缩 draw.io 均从同一解析后的 DiagramDocument 生成。
2. 首个实现限定单页、根 Component 的全部叶子实例与二端 Connection。嵌套展开、根边界、过滤、跨页、分组和注记编辑不在此次实现中；不能通过静默丢弃使输入变得可画。完整语义仍以 ADR-0017 为目标，后续项见 OQ-14。
3. SDL JSON 增加 Component 行为文件引用、六态与默认参数绑定，以及 Instance 同名参数覆盖。首版绑定有限标量和显式单位／来源，引用资源进入摘要证据；不声称已实现通用行为语言或 Modelica 联立求解。缺行为或参数时在图名和证据中降级为系统图；failed 状态直接失败。
4. 锁定 `elkjs 0.10.2` 和归档／bundle 摘要，使用本地 Node worker。提供 uv 驱动的校验下载脚本，构建时不得下载或静默替换后端。当前 Node 版本进入证据；CI 使用 Node 22，本地验收版本另记，不声称跨 Node 版本像素确定性。
5. overlay 首版仅开放节点位置和明确连接路由。移动节点需同时声明关联路由；后续检查拒绝穿设备、端点漂移及非法语义字段。尺寸、样式、注记与 draw.io 回读延后。
6. 区分 `review` 草稿生成闭环与 `engineering` 图纸检查闭环。后者要求行为完整和绑定图纸摘要的显式人工审核资产；没有审核只产出 partial，不伪造批准。工程图纸检查不是施工基线签发。
7. 同一工具链下保证确定性文本与路由结果。首版用通用 monospace 字符框，字体文件锁定及跨主机字形一致性进入 OQ-15，不能把序列化确定性解释为字体外观已验证。

## 后果与验证

有了可运行的模型→图纸→检查链路，同时保留 ADR-0017／0018 更完整的长期目标。代价是当前有明确边界，真实工程、复杂子系统和工程图标准仍需进一步验证。

`examples/hvac-system-schematic` 提供冷机、两类泵、负荷、冷却塔及两条闭合水环路；输入为概念桩数据。回归覆盖双输出端口身份、连接完整性、行为降级、参数绑定、图元端口回退、overlay 检查、过期审核、缺失后端和字节一致性。真实工程与人工审批验收仍按 scope 的完整门禁执行。

可执行协议见 [HVAC 系统图与原理图构建契约](../../spec/build/03-system-schematic.md)，不在本 ADR 重复字段定义。
