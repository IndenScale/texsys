# Tex Studio 通用 Editor 核心

日期：2026-11-07。

Tex Studio 以项目 Editor 为主体。文件资源管理器、全文搜索、源代码管理和文本文件文档由宿主提供；专业插件通过共享文档与布局插槽提供模型浏览、图纸、BOM、工况和结果等专业能力。没有专业插件时，通用模块仍可使用。

## 界面与操作

左侧 Activity Bar 默认依次显示文件资源管理器、搜索和源代码管理。专业视图从项目概览和中央工作区打开。Explorer 标题行只保留名称和更多菜单；项目根节点行承载新建文件、新建文件夹、刷新与折叠操作；根按钮和工具栏使用同一行的独立布局区域，点击区域不重叠。标题和项目名共享文字左边线，展开箭头位于其左侧。根节点收起时隐藏文件树和项目工具栏，并恢复项目名完整宽度；展开后四个操作按钮常驻显示，不依赖悬停或键盘焦点。树行高 24 px，目录层级缩进 8 px；项目根节点与树行共用 16 px 箭头槽，文件与目录共用 16 px 图标槽，同层名称保持对齐。祖先引导线在悬停或键盘焦点进入文件树时显示，当前目录分支加深；离开后隐藏。长名称省略，悬停保留完整路径。文件类型图标和编辑器路径面包屑保持一致。切换入口保留中央文档。文件与专业预览共享标签区域，打开文件不会丢失专业参数草稿；属性区根据当前文档呈现文件信息或专业属性。

- 文件资源管理器：按目录浏览，包含空目录；支持展开、折叠、键盘定位、刷新、新建文件／文件夹、文件重命名和删除。目录重命名和删除仅支持空目录；文件操作也可通过更多菜单、右键菜单和 F2 重命名进入。
- 文本编辑：多个文件标签、行号、未保存标记、保存、重新读取、前进／后退。`⌘/Ctrl+P` 快速打开，`⌘/Ctrl+S` 保存。关闭未保存文档时可以保存、放弃或取消；退出页面提示未保存内容。
- 外部修改：文件保存使用基准版本，冲突时不覆盖磁盘。可并排查看当前编辑和磁盘内容，选择采用磁盘内容，或保留编辑并更新保存基准后再保存。此比较界面提供人工选择，不执行自动合并。
- 全文搜索：Code Search 支持大小写、整词、正则、包含／排除路径、替换预览、可折叠文件分组与中央搜索结果文档。同一行多个匹配合并显示，保留全部高亮和精确列位置。详见 [Code Search 对标与实现](studio-code-search.md)。存在未保存编辑时以磁盘为准，替换前需处理相关草稿。
- 源代码管理：读取真实分支与工作区状态，区分已暂存和未暂存；查看 HEAD／暂存区／工作区对应差异，逐文件或批量暂存／取消暂存、确认后放弃工作区更改、填写说明并创建本地提交。默认显示整个仓库的变更，可在标题更多菜单切换为当前项目。支持真实提交历史图，无仓库时可初始化。

通用入口的快捷键为 `⌘/Ctrl+Shift+E`、`⌘/Ctrl+Shift+F` 和 `⌘/Ctrl+Shift+G`，也可通过视图菜单或命令面板打开。

命令中心输入 `>` 可查找命令。在文件搜索中输入 `文件名:行号` 或 `文件名:行号:列号`，按 `Enter` 打开并定位。用键盘从命令中心或 Explorer 打开文本文件时，焦点进入源码编辑器。

通过项目菜单或命令面板执行「关闭当前文档」。在 Chrome 中从 Studio 的「视图 → 全屏」进入页面全屏后，关闭文档使用 VS Code 的 `⌘W`（macOS）或 `Ctrl+W`（Windows／Linux）。在普通 Chrome 标签页中，这组键由浏览器用于关页。

在工作台文档标签上，左右方向键切换，`Home` 和 `End` 跳到首尾，`Delete` 关闭聚焦的标签，macOS 也支持 `⌫`。关闭当前标签后优先聚焦右侧相邻文档，其次是左侧。未保存确认以「取消」为初始焦点，按 `Esc` 返回原处。

## 数据范围与约束

文件操作和搜索限定在当前项目中，拒绝越界路径、符号链接、构建目录、版本库内部文件和依赖缓存。文本编辑限 1 MiB UTF-8；显示统一换行，保存保留原换行形式、BOM 和文件权限。二进制和大文件显示不可编辑原因，仍可重命名或删除。文件与目录索引各限 5000 项；搜索扫描限 32 MiB，最多返回 1000 处匹配，跳过或截断均有明确反馈。

项目可以位于父级 Git 仓库。变更列表、暂存和提交按所选范围工作。选中「当前项目」时，项目外有暂存内容会阻止提交。提交也会检查隐藏变更和未解决冲突。Git 操作校验当前状态快照，文件或索引更新后要求刷新。差异显示限 1 MiB。历史图展示真实父子关系，初次加载 50 条、最多 500 条；可按所选范围查看历史差异。界面不提供远程拉取／推送、分支操作或专用的合并冲突编辑器。

源码区使用本地打包的 Monaco Editor，提供软换行、minimap、行号和常见项目文件的语法高亮。软换行只改变显示，保存仍通过 Studio 的文件版本检查和原有编码处理。专业校验继续通过已有检查与任务能力执行。
