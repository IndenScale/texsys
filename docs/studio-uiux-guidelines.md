# Tex Studio UI/UX 设计规范

## 编辑区与预览区

**操作按钮（Action Button）只显示图标。文档级命令与标签页同排，固定在编辑区右端。** 这条规则适用于中央工作区内执行独立命令的按钮，包括文档操作、预览画布工具、结果操作、行尾操作和空状态操作。

### 内容与命令

- 第一行左侧是文档标签，右侧是当前文档的图标操作，例如源码的比较、重新读取和保存，或图纸的相机操作和工程命令。不同用途的操作分组。标签过多时，标签列表独立横向滚动，右侧操作不随标签滚动，也不换到下一行。
- 第二行是文档上下文，显示面包屑、路径、预览类型和显示模式。文档级命令不放在这一行；表格行、结果和空状态的局部命令仍跟随各自的内容。
- 文档标签、面包屑、菜单项、对象名称及视图或模式选项保留文字。它们用于识别内容、目的地或当前选项。确认对话框也保留明确的按钮文字，让用户在提交、覆盖或放弃前看清后果。
- 文件保存状态放在编辑器底部状态行；未保存的文档也在标签上显示圆点。参数草稿、运行状态、缩放比例等信息放在对应的上下文或内容区，标签栏右侧只放操作图标。

### 视觉与交互

- 新增操作使用共享的 `EditorActionButton`。按钮内容只包含共享图标库的 SVG；不使用文字、字符拼成的图标，或在宽屏显示文字再由媒体查询隐藏。相同动作在各视图使用相同图标，例如保存用磁盘、刷新用回转箭头、导出用下载、播放用三角形。
- 桌面默认按钮命中区 28 × 28 CSS px，图标 16 × 16 CSS px。默认沿用工作台灰蓝前景和浅灰悬停色；常用命令可以使用工作台浅青底强调。保持默认、悬停、按下、焦点、选中和禁用状态可辨。
- 每个图标按钮提供本地化的操作名称，用于悬停提示和无障碍名称。键盘聚焦时显示焦点框及同一提示；有快捷键时可以在提示中补充。可切换按钮使用 `aria-pressed`，不可执行时保持原位并禁用。

### 验收

在现有 Chrome 标签页查看源码、搜索结果和专业预览。确认右侧操作与文档标签同排、随当前文档切换，第二行只保留上下文。打开多个标签并缩窄编辑区，检查标签滚动时操作区仍在原位；用鼠标与键盘核对提示、焦点、禁用态和原有操作结果。

工作台的面板尺寸、相机和动效遵循[工作台空间与动效准则](studio-interaction-design.md)。

## 快捷键展示

- 每个按键使用一个 `kbd`，通过共享的 `Keycaps` 组件逐键展示。修饰键在前，主键在后。macOS 使用系统符号，如 `⇧ ⌘ E`。Windows 和 Linux 使用按键名称，如 `Ctrl Shift E`。显示的组合与实际绑定一致。
- 上下文菜单将快捷键放在菜单项右端，按键在格内居中。同一菜单的按键格等宽，单字符用 11 CSS px。有多字符键名时，该菜单统一用 32 CSS px。格间距为 2 CSS px，快捷键与菜单文字之间至少留 24 CSS px。
- 快捷键字号为 12 CSS px，字重为 550，使用弱化的前景色。菜单项的勾选状态显示在左侧。窄视口下快捷键保持为一组，菜单文字可换行。

验收时先按正常显示比例观察快捷键是否能一眼读成一组，修饰键的笔画是否清楚。再检查按键格宽度、组内间距、组与菜单文字的间距和末键右边缘，并用键盘触发菜单中显示的组合。
