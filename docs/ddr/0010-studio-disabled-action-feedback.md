# DDR-0010：就地说明操作不可用的原因

- 状态：已取代
- 日期：2026-11-08
- 取代：无
- 被取代：[DDR-0011](0011-studio-disabled-action-tooltip.md)

## 背景

源代码管理中已有变更时，用户会看到「AI 生成」按钮。暂存区为空时，按钮变灰，原因只在鼠标悬停时出现。界面没有直接说明为什么明明有变更却无法生成，也没有指出该在哪里暂存。

## 决策

- 主要操作因缺少前置条件而禁用时，在操作旁显示具体原因和可执行的下一步。提示随状态更新，直接显示在面板中，并与控件建立无障碍描述关联。悬停提示可补充操作名称与快捷键。
- 「AI 生成」只使用暂存差异。已有变更但暂存区为空时，提交说明输入框下方提示「没有暂存的更改。点击文件旁的 + 暂存，再生成提交说明。」用户通过文件行的暂存操作选择本次提交内容。
- 变更数量超过显示上限时，提示先在终端处理部分变更。等待 Git 操作、读取 AI 设置或生成草稿时，提示当前进度。条件满足后收起提示，按钮恢复可用。

## 权衡与验收

按钮保持在熟悉的位置。阻塞状态会多占一行或数行空间，窄面板中的提示随宽度换行。与点击后再报错相比，用户可以先读懂条件，再完成暂存。

在同一个 Chrome 工作台标签页中检查有未暂存变更的状态。鼠标离开按钮时仍能看见原因和下一步，辅助技术可读出提示。暂存一个文件后按钮启用，取消暂存最后一个文件后提示重新出现。生成继续沿用已确认的暂存范围和服务地址。
