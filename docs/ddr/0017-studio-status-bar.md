# DDR-0017：按工作区和活动编辑器组织状态栏

状态：已接受；状态项范围由 [DDR-0018](0018-studio-status-bar-editor-and-workbench-actions.md) 修订。

旧状态栏常驻展示项目、专业、输入修订和历史运行次数，却无法从编辑区直接定位 Git 变更、当前问题或源码行列。采用用户提供的 VS Code 截图作为布局和交互参考。

- 左侧从连接与项目开始，接 Git 分支、专业、当前问题和任务。分支打开源代码管理；问题与任务打开已有面板。问题数字来自当前专业的「问题」视图，表示当前条目数；未提供统计时保留入口，不显示零。任务运行时显示运行中的数量，其余时间显示历史记录数。
- 项目菜单展示项目路径及完整输入修订；工程结论及其适用性在问题、运行和证据记录中查看。
- 右侧只跟随获得焦点的源码编辑器组，显示行列、缩进、UTF-8 文本编码与语言。点击行列打开已有跳转操作。文件读取时归一化换行，因此暂不显示磁盘行尾。预览、差异、设置及其他视图不显示这些字段。
- 状态栏为 24 CSS 像素高的单行。窗口较窄时先收短长名称，进一步收窄时保留图标及主要入口，省略缩进和编码。
- 在状态栏右键，或将焦点移到栏内后按 Shift+F10，打开复选菜单。菜单允许逐项调整或隐藏整栏；「查看 → 状态栏」和命令面板使用同一开关。浏览器保存显示偏好。

验收重点：长分支名不遮挡主要入口；源码位置随当前组更新，预览没有残留状态；点开问题或任务后落到对应面板；菜单可勾选、关闭、隐藏及恢复，刷新后保留选择。
