# DDR-0026：USD 多选与属性浮层布局

- 状态：已接受
- 日期：2026-11-16
- 修订：[DDR-0025](0025-file-editor-shell-and-usd-inspection.md) 的场景选择与属性浮层行为

## 决策

- 右侧属性浮层占满可用高度。固定属性在上，当前选择在下。两组都存在时各占一半，并各自滚动。只有一组时占满全部高度。
- 构件树和视口使用同一份选择。单击替换选择，Ctrl+单击追加或取消单个构件。macOS 同时支持 Command+单击。构件树可用 Ctrl+Enter 或 Ctrl+空格切换单个构件。按 F 聚焦可见的选中构件。
- 多选同时高亮构件并展示各自的属性。固定属性独立于当前选择。切换选择或点击画布空白处，固定属性仍留在上方。关闭属性卡只收起该卡。

## 验收

在现有 Chrome 的同一文件预览中交替使用构件树与视口追加和取消选择，核对树、画布和属性同步。固定一张属性卡后检查上下区顺序、等高、滚动和单区满高。确认浮层位置和尺寸不改变画布。
