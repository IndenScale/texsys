# DDR-0032：智能体面板双层网格对齐、ChatGPT 风格双滑块与按 Provider 堆叠的模型目录

- 状态：已取代
- 日期：2026-11-18
- 取代：部分修订 [DDR-0031](0031-studio-agent-panel-vscode-parity.md) 的标题栏会话切换按钮、上下双层工具栏字号与图标尺度、框内模型与推理触发器样式及模型选择浮层结构；其余面板布局与 ACP 会话交互继续有效
- 被取代：[DDR-0033](0033-studio-agent-panel-qoder-redesign.md)

## 用户体验与交互背景

结合实机对比走查，DDR-0031 的顶部双栏与底部模型选择器仍存在四类体验偏差：

1. **顶部出现重复的「切换会话列表」入口**：面板标题栏与下方「会话」副栏同时渲染了 `◫` 切换会话列表按钮，职责重叠且破坏右侧按钮列对应关系。
2. **上下两层字号、图标与网格未对齐**：标题栏（`24px` 按钮／`16px` 图标）与「会话」副栏（`28px` 行高／`13–14px` 图标）尺寸不一，竖向分隔线占用布局宽度导致两层右侧按钮列错位；输入区框内主工具栏与框外次级工具栏同样存在字号和左缘列轴偏差；尚未发送首条消息时预热模型配置还会提前将「会话」副栏切换为冗余的 `← Harness · Harness` 与「就绪」胶囊。
3. **模型触发器与配置浮层拆分且控件冗余**：框内同时摆放胶囊底色 `[✨ 模型 · High]` 与独立 `[⇄]` 按钮，分段按钮组占用过多面积，缺少直观的上下文窗口调节。
4. **模型面板按 Harness 切选项卡且名称冗长**：模型行尾部重复拼接 `· DeepSeek Harness`、`· Antigravity (ACP)` 等来源后缀，顶部用选项卡隔离来源，无法直接按 Provider 浏览与全文检索。

## 设计决策与规范约束

### 1. 顶部双栏与底部双层工具栏严格同尺度网格对齐

- **移除顶部重复按钮**：删除面板标题栏中的 `◫` 切换会话列表按钮，「切换会话列表」仅保留在第二层「会话」副栏（及对话态标题条）最右侧。
- **顶部两层完全同尺度对齐**：面板标题栏与「会话」副栏统一采用 `var(--editor-tab-height)` 行高、`0 8px` 水平内边距、`24×24px` 按钮尺寸、`4px` 按钮间距、`16px` 图标尺寸与 `12px`（字重 `500`）标题文字；最大化按钮左侧的竖向分隔线采用零布局宽度伪元素居中绘制在 `4px` 间距内，使第一层 `⋯ / ⛶ / ✕` 与第二层 `🔍 / ▽ / ◫` 右侧三列像素级垂直对齐，左侧「智能体」与「会话」文字同列起齐。
- **输入区两层同尺度对齐**：框内主工具栏与框外次级工具栏统一采用 `24px` 控件高度、`14px` 图标尺寸与 `12px`（字重 `400`）文字，次级工具栏左内边距补偿输入框外边距与内边距，使框内 `+` 图标与框外运行环境图标处于同一垂直列轴。
- **预热态保持空白欢迎与会话副栏**：仅在真正产生对话内容、标题或待发消息时切换为对话态标题条；未对话前点击模型触发器预热会话以拉取配置时，继续保留欢迎视图与「会话」副栏，且对工具栏与浮层标注 `translate="no"` 防止浏览器翻译扩展注入双语重复文本。

### 2. ChatGPT 风格框内模型触发器与双滑块调节浮层（第一级）

- **框内无框内联触发器**：移除 `✨` 图标、胶囊底色框与独立的 `⇄` 按钮，改为紧凑的 ChatGPT 风格内联触发器，仅依次呈现精简模型名称、当前推理强度与当前上下文窗口（及下拉箭头 `⌄`），静止态透明、悬停态柔和显底。
- **模型调节浮层（`controls` 视图）**：点击框内模型触发器打开紧凑浮层：
  - **顶部模型切换行**：全宽展示当前模型名称与右向箭头 `›`，点击进入模型目录视图。
  - **下方双胶囊离散滑块**：依次提供「推理强度」与「上下文窗口」两个离散档位滑块（圆角胶囊轨道、离散刻度圆点与圆形白底滑块拇指），支持指针拖拽实时预览、松手吸附提交、`Escape` 取消拖拽回滚，以及 `ArrowLeft`／`ArrowRight`／`Home`／`End` 键盘无障碍调节。当智能体声明 2 个及以上档位时直接调用 `/api/agent/config` 更新配置；当智能体未提供可调档位时保持禁用滑轨并如实展示当前上下文容量（如 `200K`、`1M`）或「默认」。

### 3. 顶部搜索与按 Provider 纵向堆叠的模型目录（第二级）

- **顶部直出搜索框**：模型目录视图最顶部直接放置无前缀图标的 `搜索模型…` 输入框，与下方分组标题及模型名称共享同一 `14px` 左缘基线，不设任何顶部工具条或来源选项卡。
- **按 Provider 分组纵向堆叠**：解析并保留 ACP `ConfigOptionGroup` 声明的 Provider 分组（如 `DeepSeek`、`kimi-coding`、`omlx`），对扁平模型项从取值元组、前缀或模型家族归纳 Provider，跨已连接来源合并去重后纵向堆叠展示，彻底取消 Provider／Harness 切换选项卡。
- **精简模型命名**：剥离模型名称中的 `· DeepSeek Harness`、`· Antigravity (ACP)`、`provider/` 前缀与 JSON 元组包装，模型行仅展示纯净模型短名，右侧仅对当前选中项显示 `✓`，不再渲染冗余的来源副标题。按 `Escape` 先退回第一级双滑块视图，再按 `Escape` 关闭浮层；快捷键 `⌘⇧M`／`Ctrl+Shift+M` 可直接打开模型目录。

## 体验影响与权衡

- 将模型调节与模型目录分层后，高频调整推理强度或上下文窗口只需单次点击即可拖动滑块，浏览完整多 Provider 目录也拥有更纯粹的搜索与滚动空间。
- 对未通过 ACP `configOptions` 暴露上下文窗口枚举的智能体，滑块以禁用态如实呈现已上报容量或「默认」，不伪造后端未支持的截断参数。

## 可用性走查与验收标准

1. 检查面板顶部两层：确认标题栏不再出现 `切换会话列表` 按钮，两层图标均为 `16px`、标题文字均为 `12px`，左侧标题与右侧三列动作按钮严格垂直对齐。
2. 检查输入区两层：确认框内仅保留 `+` 与 ChatGPT 风格内联模型触发器（无 `✨` 与 `⇄`），两层图标均为 `14px`、文字均为 `12px` 且左缘对齐。
3. 点击模型触发器：确认上方为模型切换入口、下方为「推理强度」与「上下文窗口」两个胶囊滑块；点击顶部模型名进入第二级后，确认最顶部为搜索输入框、下方按 Provider 纵向堆叠、无选项卡且模型行无 `· Harness` 后缀。
