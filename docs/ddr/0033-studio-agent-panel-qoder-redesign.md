# DDR-0033：对标 Qoder 重新设计智能体面板

- 状态：已接受
- 日期：2026-11-18
- 取代：[DDR-0031](0031-studio-agent-panel-vscode-parity.md)、[DDR-0032](0032-studio-agent-panel-grid-and-model-sliders.md)；部分修订 [DDR-0030](0030-studio-agent-panel.md) 的标题栏、欢迎内容、会话列表与输入框（右侧专职面板、双工作区隔离、修改走源代码管理继续有效）
- 被取代：无

## 用户体验与交互背景

DDR-0031／0032 以 VS Code 开源聊天视图为参照，结果把工程实现的结构直接摆到了界面上：面板顶部两层工具栏（标题栏 + 「会话」副栏，共 7 个图标）、输入框内外两层工具栏、Harness 与权限胶囊、模型浮层的双滑块与 Provider 目录、调试日志、视图模式子菜单。每个控件都“有用”，合起来却没有视觉重心，第一次打开面板的工程师看到的是一排配置，而不是“可以开始对话”。

对照 Qoder IDE 的智能体面板（2026-11-18 截图走查），它用更少的元素完成同样的任务：

1. **会话即标签。** 顶部只有一行：会话标签 + 右侧「新建会话」「对话历史」两个图标。没有面板标题、会话副栏和筛选器。
2. **空态有品牌与重心。** 左对齐的大号标语、两行说明，大面积留白；选择「专家团」时下方列出几条可点的任务示例。
3. **输入区是一块安静的平面。** 无边框多行输入，占位符直接说明 `@` 添加上下文、`/` 使用命令；底部一行只有模式、模型两个文字触发器，以及右侧实心发送按钮。
4. **详细信息放在侧挂浮层。** 模型列表只列名称；悬停一行在左侧浮出说明卡，点击编辑图标在同一位置展开上下文窗口与思考模式设置，不挤占列表。
5. **历史是一个可搜索的快速选择器**，而不是常驻侧栏。

与此同时，[ADR-0035](../adr/0035-deepseek-harness-as-agent-kernel.md) 把 DeepSeek Harness 定为唯一内核，Harness 选择器、登录、多来源模型合并都不再需要。Qoder 中与订阅计费相关的元素（模型倍率、错峰折扣横幅、用量百分比、Credit 消耗、添加自定义模型）不属于本产品，全部不引入。

## 设计决策与规范约束

尺寸、颜色和组件的具体取值见 [智能体面板设计系统](../../spec/studio/02-agent-panel-design-system.md)；本节记录结构性决策。

### 1. 信息架构：三段式

面板自上而下只有三段：**会话标签栏 → 对话区 → 输入区**。删除面板标题「智能体」、会话副栏、会话筛选、视图模式、调试日志、Harness 胶囊、权限胶囊和上下文用量环外的所有常驻控件。

### 2. 会话标签栏

- 高度与编辑器标签栏一致。每个标签代表一个打开的会话：对话图标 + 会话标题（首条消息，单行截断）；未发送消息的标签显示「新会话」。当前标签使用画布底色并与对话区连成一体，其余标签无底色；悬停或当前标签显示关闭按钮。
- 右侧固定三个图标按钮：`+` 新建会话、`history` 对话历史、`⋯` 更多。`⋯` 只放低频操作：在源代码管理中审查修改（项目工作区）或打开已启动的项目（空白工作区）、本会话自动批准工具授权、最大化／还原面板、关闭面板。
- 新建会话只创建本地草稿标签，首条消息发送时才启动内核进程。已有空草稿标签时，「新建会话」聚焦它而不是再开一个。
- 关闭标签会结束该会话的内核进程，会话仍保留在历史中，可随时恢复。最后一个标签关闭后自动留下一个空草稿标签。同时打开的会话不超过 8 个。

### 3. 对话历史选择器

- 点击 `history` 在标签栏下方右对齐弹出选择器：顶部标题「对话历史」，其下为搜索框，列表按「今天／昨天／近 7 天／更早」分组，每行显示会话标题与相对时间；当前打开的会话带圆点标记。悬停行显示删除按钮。
- 没有历史时，搜索框占位符显示「暂无对话历史」，不渲染额外的空态插画。
- ↑／↓ 移动，Enter 打开，Escape 关闭。打开已在标签中的会话只切换标签；否则后端恢复该会话并新开标签，已保存的对话先按原样显示，其后以「以上为历史记录」分隔线标识恢复点。内核无法恢复时，记录仍可阅读，输入区提示新建会话继续。
- 删除历史只删除 Studio 侧记录（ADR-0035），需要二次确认。

### 4. 空态

- 对话区为空时显示品牌空态：Tex Studio 标志、两行标语「看清系统」／「验证每一次修改」、两行说明。左对齐，位于对话区上方三分之一处，不居中堆叠卡片。第二行首字使用强调色渐变，标语其余部分使用低对比灰色，避免与真实内容争夺注意力。
- 标语下方列出 2–3 条任务示例（图标 + 一行文字），点击把示例文本填入输入框并聚焦，不直接发送。项目工作区示例：解释当前文件（仅在有活动文件时出现）、运行构建并解读失败、评估最近修改的影响范围；空白工作区说明当前未打开项目，智能体只在独立缓存目录中工作。
- 内核不可用（未找到 `dsh` 或启动诊断失败）时，空态下方显示一条说明与修复命令，不再展示 JSON 配置示例。

### 5. 对话区

- 用户消息使用浅底色块，附带的文件以小号标签列在消息下方；智能体回答为无底色的 Markdown 正文；思考过程默认折叠为一行「思考过程」。
- 工具调用默认是一行：状态图标、动作、路径或命令（等宽、弱化），可展开查看差异、终端输出或结果；失败的工具默认展开。路径可点击打开文件。
- 授权请求使用强调色浅底卡片，允许类选项为主按钮。错误与停止原因以一行弱化文本呈现。
- 回答结束后悬停显示复制按钮；离开底部时浮现「滚动到底部」按钮。

### 6. 输入区

- 输入区与对话区之间只有一条分隔线，没有外框和卡片阴影。从上到下依次为：可选的修改清单条（「智能体修改了 N 个文件」+「审查修改」，仍不提供接受／拒绝）、上下文文件标签、无边框多行输入框（2–8 行自适应）、底部工具行。
- 占位符：「规划与修改，@ 添加上下文，/ 使用命令」。输入 `@` 弹出项目文件选择，选中后作为上下文标签加入；输入 `/` 列出内核声明的命令。当前编辑器文件作为可切换的上下文标签自动附带，选择记入浏览器偏好。
- 底部工具行左侧为模型触发器（仅模型短名 + 下拉箭头），右侧为上下文用量环（仅在内核上报后显示）和实心发送按钮。处理中发送按钮变为停止按钮；Enter 发送，Shift+Enter 换行，输入法组合期间不发送，处理中 Escape 停止。
- 不设模式选择器。DSH ACP 不提供模式（ADR-0035），只有一个选项的选择器不显示；Qoder 的「智能体／智能问答／专家团」待内核提供对应能力后再引入。不设语音输入与提示词增强按钮。

### 7. 模型菜单

- 点击模型触发器在其上方弹出模型列表；多个提供方时以小号分组标题区分，只有一个提供方时不显示分组标题。行内只显示模型名称，当前模型高亮并在行尾显示编辑图标。
- 悬停任一行，在菜单左侧（空间不足时在右侧）浮出说明卡：模型名、内核提供的说明，以及确有数据的属性（提供方、当前思考强度、上报的上下文窗口）。缺失的属性不显示，不编造参数。
- 点击编辑图标，在同一位置展开设置卡：「思考模式」开关（关闭即 `off`）及其档位列表，当前档位打勾；内核声明上下文窗口配置时再显示「上下文窗口」选项组。设置即时通过 `/api/agent/config` 生效。
- 用户最近选择的模型与思考档位记入浏览器偏好，新会话就绪后若与内核默认不同则自动应用。
- 草稿标签首次打开模型菜单时预热内核会话以取得真实模型列表；预热不切换为对话态，也不进入历史。

## 备选方案

- **继续以 VS Code 为参照、只做视觉精简。** 不采用：问题在信息架构（两层工具栏、常驻配置胶囊），不在颜色和间距。
- **完全照搬 Qoder 深色主题。** 不采用：Tex Studio 工作台是浅色主题，面板单独深色会割裂；只吸收其结构、层级和克制的控件用法，颜色映射到工作台色板。
- **会话列表常驻在面板顶部。** 不采用：历史属于低频查找操作，标签已覆盖“正在进行的会话”，常驻列表会挤占对话空间。
- **保留模式选择器并只放一个「智能体」。** 不采用：单选项选择器只增加噪音（与 [AGENTS.md](../../AGENTS.md) 中“只有一个可用打开方式时不显示选择器”一致）。

## 体验影响与权衡

- 面板常驻控件从约 14 个减少到 6 个（3 个标签栏图标、模型触发器、发送按钮、条件出现的用量环）；权限、视图和调试类开关移入 `⋯` 或删除。依赖 DDR-0031 「显示智能体调试日志」排查内核问题的用户，改为查看错误卡片中的内核 stderr 摘要与集成终端。
- 会话改为标签后，同时进行多个会话更直观；关闭标签即结束进程，避免后台残留会话占满上限。
- 双滑块被档位列表取代，调整思考强度需要“打开菜单 → 编辑 → 选择”三步，但模型菜单本身更轻；高频用户的选择会被记住。
- 历史恢复依赖 Studio 保存的呈现日志，若 DSH 内部压缩过上下文，继续对话时模型看到的上下文可能少于界面显示的记录。

## 可用性走查与验收标准

1. 空白工作区与项目工作区首次打开面板：顶部只有「新会话」标签和 `+`／历史／`⋯` 三个图标；对话区显示标志、两行标语、说明与示例；输入区只有输入框、模型触发器和发送按钮。
2. 点击示例只填入输入框；输入 `@` 能选择项目文件并生成标签，输入 `/` 列出命令；Enter 发送后标签标题变为消息摘要。
3. 新建第二个会话、在两个标签间切换，两个会话的对话与状态互不串扰；关闭标签后该会话出现在历史中。
4. 打开历史选择器，搜索、键盘选择并恢复一个会话：先显示原有记录和「以上为历史记录」分隔线，随后可继续对话。重启 Studio 后历史仍在。删除一条历史需确认。
5. 打开模型菜单：只有模型名，没有倍率、折扣或用量；悬停出现说明卡，编辑图标展开思考模式设置，切换档位后新的档位立即生效并在新会话中沿用。
6. 在 280 px、默认宽度与最大化三种宽度下，标签标题截断、按钮不被挤出，浮层不超出视口；所有浮层支持 Escape 与点击外部关闭。
