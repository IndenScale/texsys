# DDR-0011：在浮层中说明操作不可用的原因

- 状态：已接受
- 日期：2026-11-08
- 取代：[DDR-0010](0010-studio-disabled-action-feedback.md)
- 被取代：无

## 背景

源代码管理的「AI 生成」需要暂存内容。把前置条件和操作步骤放在提交说明框下方，文字会随侧栏宽度和界面语言换行。暂存状态切换时，提交按钮和变更列表会跟着上下移动。

## 决策

- 主操作保持原位，用禁用样式表示当前不可执行。鼠标悬停或键盘聚焦时，在控件旁的浮层里显示原因和下一步。浮层独立于面板布局，文本可换行。移开指针、移走焦点或按 Escape 可收起提示。
- 禁用的操作仍可聚焦，向辅助技术报告禁用状态和原因。点击、Enter 或空格都不会触发操作。
- 暂存区为空时，「AI 生成」的浮层说明如何用文件旁的 暂存。等待 Git 操作、读取 AI 设置或生成草稿时，浮层显示对应状态。发起生成后的服务地址确认与错误反馈保留在操作流程中。

## 验收

在同一个 Chrome 工作台标签页中用鼠标和键盘检查提示。打开或收起浮层时，提交按钮和变更列表的位置保持一致。暂存一个文件后按钮启用，取消暂存最后一个文件后，按钮恢复禁用并提供原因。缩窄侧栏后确认浮层可换行且文字仍可读。
