# DDR-0027：USD 预览器的资源、属性、导航与构件选择

- 状态：已接受
- 日期：2026-11-16
- 关联：[DDR-0024](0024-studio-usd-scene-view.md)、[DDR-0025](0025-file-editor-shell-and-usd-inspection.md)、[DDR-0026](0026-usd-selection-and-inspection-layout.md)

## 背景

工程师打开协调场景后，需要先辨认密集管线中的一个构件，再检查其属性和来源，或保留它与相邻构件对照。原悬浮提示中的 `Cube` 只说明 USD 几何类型，速览卡补充已声明的工程字段。协调场景走查后保留原有填色反馈。批量选择由用户按住修饰键逐件完成。

## 资源面板

- 左侧资源面板以「构件」为标题，按当前 USD 的 Prim 层级呈现可检查对象。工作台资源管理器和快速打开负责进入文件，构件树负责在文件内定位。分组节点负责展开和折叠，选择分支中的具体对象属于独立操作。
- 搜索按对象名、Prim 路径和已有工程字段缩小树的结果。分类筛选按模型实际声明的专业、楼层、分区、材料、构件类型和集合缩小树与视口范围。同一分类中的多值取并集，跨分类取交集。资源面板提供清除筛选、隐藏筛选结果和恢复显隐操作。
- 视口选中对象时，树展开对应路径，并在节点可见时滚动定位。树与视口共享选择集。树行能够分别表达键盘焦点、选择和隐藏状态，搜索、折叠与可见性设置只影响展示。

## 属性面板

- 点击或键盘选择构件后，在视口右侧打开构件属性面板。同一区域中固定属性在上、当前选择在下，两组各占一半可用高度并独立滚动。只有一组时占满高度。浮层前后画布尺寸保持一致。
- 固定属性后继续浏览或更换选择，原卡保留。同一对象在两组间至多出现一次。取消固定时，若对象仍选中，卡片回到当前选择区。关闭卡片仅收起属性，保留对象的选择状态。单击画布空白处清除选择并收起当前选择区，固定区继续显示。
- 面板提供 Prim 路径、所属构件、包络尺寸、标高和已声明的工程属性。字段有单位、来源或设计状态时一并表达，缺失字段按模型实际提供的内容省略。包络与测距来自当前场景几何。存在源映射时，通过「定位源码」打开普通编辑器。聚焦、显隐、半透明、隔离以及恢复显隐属于视图操作。

## 导航操作

- 预览在普通文件标签中打开。缩放、适应视图、标准视图、剖切、测距和全屏使用当前编辑器组控制栏。速度、加速倍率、鼠标转向灵敏度和快捷键说明在全局设置的「USD 场景预览」中。
- 视口获得焦点时，左键拖动旋转，右键拖动平移，滚轮或 `+`／`−` 缩放。`W/A/S/D` 水平移动，`Q/E` 下降或上升，方向键转向，`Shift` 加速。`F` 聚焦可见的选中构件，`Home` 适应可见范围，`Enter` 重新打开已选构件的属性。
- 键盘进入视口时，左上角的局部标记持续表示导航焦点。鼠标接管或焦点离开时标记消失。焦点在搜索框、构件树或属性面板时，由该控件接收相应输入。树的方向键移动焦点或展开、折叠分支。切换到另一编辑器组或窗口失焦时停止持续导航。
- `Shift+F` 切换工作区内场景全屏。退出后恢复编辑器组和工作台布局，保留该场景的相机、选择与固定属性。测距期间，画布点击采集表面点，`Esc` 先退出测距，再用于退出全屏。

## 构件选择

### 悬浮与速览

- 指针命中后保持现有悬浮填色，已选构件保持更深、持续的选中填色。悬浮经过已选构件时保留选中样式。
- 在同一对象上停留约 300 ms 后，显示紧凑的构件速览卡。第一行是构件名称，优先用模型声明的工程名称。第二行最多展示两至三个有辨识度的已声明字段，例如类型、专业和分区。可展示为「BuswayA2」和「母线槽 · 电气 · POWER-ROOF」。缺少工程字段时退回可识别的 Prim 名称或路径，省略空行。`Cube`、`Mesh` 等几何类型保留在详细属性中。
- 速览卡靠近命中点放置，临近视口边缘或属性浮层时换侧或限制在剩余空间内，卡片保持指针事件穿透。切换目标时重算停留时间。指针移出、移动相机或命中失效时清除悬浮反馈。悬浮状态独立于选择、焦点和固定属性。

### 单击与批量选择

- 树和视口的普通单击都将选择替换为当前构件并打开属性。视口按实际可拾取的表面命中。拖动相机期间保持原选择。构件树的 `Enter` 或空格可选择当前焦点对象。
- 按住 `Ctrl` 连续点击，将每个构件逐项加入同一个选择集，再点已选构件即移出。macOS 也支持 `Command`。构件树提供 `Ctrl` 或 `Command` 配合 `Enter`／空格的等价操作。修饰键点击空白处保留选择，普通点击空白处清除选择。可交替使用树和视口，多选中的可见构件同时高亮。每次添加都由用户点明对象，搜索和筛选只改变展示范围。

## 取舍

在协调场景中，额外的双色轮廓会沿细长构件形成连续亮边，干扰对相邻管线的辨认。保留填色反馈，速览延迟出现，以减少扫过密集几何时的文本跳动。完整属性留在右侧，便于滚动、复制、追溯来源及固定对照。按住修饰键逐项多选让工程师控制对照的对象，搜索与筛选仍用于定位。

## 走查与验收

1. 在既有 Google Chrome 的 Tex Studio 中通过快速打开进入 AIDC 协调场景。扫过屋面母线和桥架，检查悬浮填色和选中填色。停在同一对象后显示速览，快速扫过、移动相机及移出时检查速览及时消失。
2. 使用搜索和专业筛选缩小范围，交替从构件树和视口选择与取消两个对象。固定其中一张卡后检验排序、等高滚动、取消固定和空白点击，比较属性出现前后的画布尺寸。有源映射时从面板进入源码，核对对象身份和来源。
3. 使用普通分层 USD 走查，在缺少工程元数据时按 Prim 定位并检查属性。用 `Tab` 和 `Shift+Tab` 在视口与资源面板之间移动，确认方向键作用于持有焦点的区域。在分栏和全屏下检查焦点、导航、测距退出和布局恢复。
