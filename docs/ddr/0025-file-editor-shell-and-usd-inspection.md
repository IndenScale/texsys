# DDR-0025：文件编辑器外壳与 USD 属性检查

- 状态：已接受
- 日期：2026-11-16
- 修订：[DDR-0014](0014-studio-editor-group-actions-and-disk-comparison-removal.md) 的「配置编辑器」入口，以及 [DDR-0024](0024-studio-usd-scene-view.md) 的工具栏、设置入口和属性区布局
- 关联：[DDR-0002](0002-studio-uiux-guidelines.md)、[DDR-0012](0012-studio-file-preview-and-source.md)、[DDR-0021](0021-studio-statusbar-flush-and-empty-workbench-parity.md)

## 带来错误设计的假设

上一轮把 USD 预览当成了可以自行组织界面外壳的独立应用。这个假设使场景重复提供菜单和工具栏、设置入口以及状态栏，还让构件属性脱离了当前选择。USD 预览的身份是一种文件编辑器或预览器。Tex Studio 已经为打开的文件提供编辑器组、控制栏、全局菜单、全局设置和全局状态栏。

## 决策

- 文件预览器提供文件内容和与内容直接相关的交互。文件预览器不得创建独立菜单栏、工具栏或状态栏。菜单和编辑器操作使用工作台已有入口。新增场景命令进入当前编辑器组的控制栏，操作按钮只展示图标，名称通过 Tooltip 和无障碍标签提供。下拉命令通过同一控制栏展开。
- 偏好通过全局设置进入。全局设置保留「USD 场景预览」分类。移除编辑器内的设置按钮及更多操作中的「配置编辑器」。全局状态栏由工作台管理。文件内容区禁止自建状态栏。
- 构件树常驻左侧。单击树节点或视口中的构件都立即在视口右侧浮出属性卡。默认只有一张跟随选择的卡。锁定某张卡保留对应构件，继续选择时更新跟随卡。清除画布选择只收起跟随卡，每张卡可单独关闭。右侧浮层不挤占左树或改变相机视口的尺寸。
- 工作区全屏继续展开当前文件预览，保留同一编辑器控制栏。导航快捷键仍属于获得输入焦点的场景，浏览偏好由全局设置管理。

## 验收

打开普通 USD 文件，在分栏及工作区全屏中确认场景命令处于既有控制栏，按钮没有可见文字，设置与状态栏只有全局入口。分别从树和视口选构件，检查跟随卡、锁定卡、重新选择与关闭行为，并确认右侧浮层出现前后视口尺寸一致。
