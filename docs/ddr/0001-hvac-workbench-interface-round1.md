# DDR-0001：HVAC 工作台第一轮界面改造与信息架构

- 状态：已接受
- 日期：2026-11-06
- 取代：无

目标是落实 EDA 类工作台的信息架构与连续交互，提升现有本地能力的可用性。产品与专业边界沿用 [ADR-0021](../adr/0021-tex-studio-plugin-based-disciplinary-workbenches.md)，接入行为以 [工作台契约](../../spec/studio/01-workbench.md) 为准。

## 信息架构与组件复用

界面采用 AtomStudio 编辑器组件与分栏布局的 React 适配层，来源、摘要与 MIT 许可保存在 `src/texsys/assets/studio/atomstudio/`。仅引入界面组件，HVAC 数据模型、绘图、参数保存和计算链路继续由 texsys 维护。

标题栏仅保留纯色窗口控制预留区、后退／前进、三个面板开关与居中的项目命令入口。项目 → 专业 → Git 分支移入底部状态栏，分支不与输入修订混淆。原生菜单与浏览器呈现边界见 [标题栏与菜单命令](0004-studio-titlebar-and-menu.md)。

| Activity   | 独占左侧的资源内容       | 打开资源后的中央内容       |
| ---------- | ------------------------ | -------------------------- |
| 系统对象   | 系统根节点、搜索与设备树 | 图纸、设备表、对象属性联动 |
| 器件类型库 | 类型搜索与项目类型清单   | 类型定义及只读默认参数     |
| 工况与分析 | 工况配置、结果、问题入口 | 仿真配置、曲线与检查       |
| 成果文件   | 当前与历史成果文件       | 成果清单与导出             |
| 项目文件   | 系统模型和项目概览入口   | 只读源数据与概览           |

Activity 互斥显示，资源占满左栏；切换 Activity 不改变当前文档，打开具体资源才进入对应内容。各资源页隐藏保留搜索与滚动位置。中央采用导入的文档标签、上下文行和画布结构，取消重复大标题和常驻任务状态条；底部将问题和任务日志互斥呈现。左右与底部分栏复用导入的拖拽、键盘调宽和双击复位交互。属性面板隐藏时保留参数草稿。

正文与工程参数采用 13–14 px。图面沿用工程图元与冷冻水、冷却水语义颜色，操作使用深青色，工作区使用白色和石板灰。仿真配置保持紧凑，首屏优先曲线、运行上下文与约束。

## 关键交互

1. 类型与实例分开选择。类型默认参数只读，可以查看使用实例，再进入实例参数覆盖。
2. 点击参数后直接在当前属性区编辑，不再滚动到整个参数列表底部。六态、单位和来源保留；止回阀显示有／无，泵效率展示百分比，编辑保留原始单位与数值。
3. 草稿显示于工具栏、相关文档标签与属性区。切换文档、收起面板保留草稿；切换对象时提示先保存或放弃；有草稿时禁止提交计算。
4. 设计参数与结果叠加显式切换。结果叠加显示工况、求解后端、时刻及输入状态，历史结果不叠加到当前图面。
5. 检查与问题汇集模型诊断、图纸审核待办和工况失败约束。点击约束可联动实例、曲线变量、阈值与首次越限采样点，再从该时刻返回图面。
6. 模型检查与图纸检查按报告类型独立保留，防止新检查遮掉已有图纸待办。无显式对象身份的诊断保留原问题，不提供猜测定位。
7. 任务提交后通过提示与顶部运行标记反馈，不自动展开日志面板。后台任务可打开相应专业的结果视图，执行完成与工程结论分别显示；全部工况使用批次结论，单个工况保留自身结论。
8. 模型源数据支持按对象路径定位与文字高亮；成果区集中导出，并区分当前输入和历史输入。

## 本地验证

隔离验证项目位于本机忽略目录 `build/evidence/studio-round1/project/`，来自 `hvac-dynamic-station`，原示例源输入不用于交互写入。初轮截图与验证数据保存在 `build/evidence/studio-round1/`；组件导入后的 Chrome 截图保存在 `build/evidence/studio-layout-import/`。

验证覆盖空成果状态出图、类型默认值与实例入口、参数 22 m → 23 m 的草稿和保存、切换对象保护、跨文档草稿保留、历史图纸提示、恢复继承、真实 SciPy 工况运行、约束定位与结果叠加、任务结果入口、成果导出、文档关闭和键盘切换、面板调宽与窄屏布局。

定位语义、对象引用边界、同名类型／实例源定位、六态数值展示及历史问题关联由 `tools/test_studio_ui.mjs` 回归；后台报告共存由 `tests/test_studio.py` 回归。此文档记录本地界面与软件行为验收，不作为实际工程参数、厂家校准、远程协作或正式提资验收。

本次组件导入另行在 Chrome 检查 Activity 独占与文档独立、顶部布局开关、参数草稿跨面板保留、对象切换保护、分栏键盘与拖拽、文档标签和底部问题／任务切换。

## 后续能力边界

本轮提供现有能力的完整工作组织。拓扑编辑、器件类型创建、可编辑模型源、工况配置编辑、空间布置与管线路由、方案比较、正式提资及项目创建／切换仍需各自的领域与持久化实现。界面没有伪造这些能力的执行入口。
