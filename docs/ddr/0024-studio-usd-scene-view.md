# DDR-0024：USD 场景浏览与构件检查

- 状态：已接受
- 日期：2026-11-16
- 关联：[DDR-0012](0012-studio-file-preview-and-source.md)、[DDR-0014](0014-studio-editor-group-actions-and-disk-comparison-removal.md)、[范围契约](../scope.md)

## 决策

- USD 继续通过普通文件标签打开。「场景全屏」由工作区暂时展开当前编辑器组中的场景，保留窗口标题栏、状态栏和场景操作。全屏入口包含场景工具栏、Shift+F 和命令面板。退出恢复编辑器组、侧栏和终端布局，保留同一场景的相机和检查状态。
- 激活 USD 预览标签即进入浏览。WASD 水平移动，Q/E 升降，方向键转向，Shift 加速。F 聚焦选中项，Home 适应可见范围。左键拖动旋转，右键拖动平移。搜索框、构件树和分隔线各自处理其输入。命令面板提供「聚焦场景视口」。
- 构件树在场景左侧常驻。搜索用于定位树节点，分类筛选用于改变视口显隐。选中构件后可显式打开属性区。属性在树下方独立滚动，可用鼠标或键盘拖动分隔线调整高度。固定属性锁定正在查看的构件，取消固定后跟随当前选择。相机、属性布局和固定对象按编辑器视图保存。
- 「USD 场景预览」是设置内的独立分类，提供速度、加速倍率、鼠标转向灵敏度和快捷键一览。导航偏好在当前浏览器内保存，场景可直接打开对应设置。

## 验收

使用现有 Chrome 对钢框架和协调场景检查打开后焦点、移动与转向、全屏布局恢复、固定属性后切换选择、分隔线调整、设置持久化。分栏时核对键盘仅操控获得焦点的一侧。可重跑的证据与待验证事项记录在[工程 POC 台账](../engineering-poc.md)。
