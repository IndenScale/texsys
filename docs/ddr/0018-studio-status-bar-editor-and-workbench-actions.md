# DDR-0018：先提供通用 IDE 状态，再增加工程入口

状态：已接受

修订 [DDR-0017](0017-studio-status-bar.md) 的状态项范围。采用用户提供的 VS Code Web 和桌面版截图对标。

- 左侧依次是宿主、Git 分支和「问题」，然后是项目和专业等 Tex Studio 项。错误、警告各有图标和计数，共用一个按钮、悬停区与键盘焦点。计数来自打开的源码模型，点击进入「问题」面板，诊断项可回到源码行列。工程问题继续按专业统计，在同一面板中独立呈现；任务与日志沿用原入口和面板。
- 右侧源码项包括光标与选区、缩进、编码、行尾、语言状态与语言模式。缩进选项和语言模式作用于当前文件的共享源码模型；显式转换缩进修改文档内容。切到预览、差异、设置或将焦点移到终端时收起源码项；通知仍可打开。
- 文件 API 报告实际 UTF-8 BOM 和行尾类型。编码支持 UTF-8 与 UTF-8 BOM，行尾可设 LF 或 CRLF。修改进入同一文件草稿，随普通保存或另存为写入，并沿用外部版本保护。编码单独改动时保留既有行尾字节。
- 通知显示本次会话最近 25 条工作台提示，可清除。屏幕阅读器支持由源码设置或命令面板开启，启用后状态栏可恢复自动检测。键盘布局仅显示浏览器实际提供的键位；AI 状态接到已有的本机 AI 设置，已配置不等于已验证可连通。
- 本地宿主菜单提供新建窗口和连接失败后的重试；Git 分支打开源代码管理。远程工作区、Git 分支切换／发布、Copilot 和桌面第三方扩展需要各自的宿主能力，不显示无效操作。
- 配置菜单先列通用项，再列 Tex Studio 项；编辑器字段仅在对应上下文列出。隐藏偏好沿用已有浏览器存储。

验收：用真实 JSON 错误确认合并按钮和源码定位；切换语言后重新生成诊断；检查 CRLF 到 LF、UTF-8 到 UTF-8 BOM 的实际字节以及过期版本拒绝覆盖；检查终端焦点、通知和屏幕阅读器开关。
