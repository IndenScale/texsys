# DDR-0029：编辑／预览区的查看方式与场景机位

- 状态：已接受

- 修订：[DDR-0013](0013-studio-editor-actions-and-open-with.md) 和 [DDR-0014](0014-studio-editor-group-actions-and-disk-comparison-removal.md) 的同组查看方式快捷按钮，[DDR-0027](0027-studio-usd-preview-interaction.md) 的场景缩放与标准视图入口

## 编辑／预览区

### 查看方式选择器

- 对有多种查看方式的文件，使用文件路径导航右侧的「打开方式」选择器切换当前编辑器组的模式。选择器显示当前方式，菜单列出此文件支持的方式并标记当前项，提供按实际扩展名设置默认值的子菜单。
- 标签操作栏不重复提供在同组切换「源代码」或「预览」的按钮。Markdown、USD、图纸和其他可预览文件执行同一规则。只有一种查看方式的文件直接使用该方式。
- 「分栏预览」在相邻编辑器组打开同一文件的预览，「分栏」复制当前打开方式。两组保持各自的查看方式，共享文件内容和保存状态。

### 场景相机

- 首次打开场景时，按可见几何的屏幕投影、深度和实际画布宽高比适配默认等轴测画面，并为画布内导航控件留出空间。已保存的编辑器组相机优先；从源码返回或几何刷新时继续使用该相机。
- 画布左下角使用独立滑杆连续调节缩放，随画布滚轮、缩放快捷键和机位同步。适应视图和剖切、测距、全屏一起放在标签栏右侧。画布内的立方体按钮名为「等轴测」，点击直接回到等轴测。旁边的向上箭头独立打开菜单，用于选择指定视角或固定机位。按住 Command 可从滑杆或按钮开始拖动整组，松手后保留在画布内。位置随编辑器组中的场景视图保存，分栏和全屏按当前画布比例调整。
- 在视角菜单中将当前相机保存为命名机位，点击名字可恢复相机位置、观察点、投影方式和缩放。机位按项目和场景路径保存在当前浏览器，重载后仍可选择，可以从同一菜单删除。机位是演示偏好，工程场景和构建产物由文件和工具链管理。

## 验收

1. 通过普通文件入口打开 AIDC 建筑协调场景和另一份比例不同的 USD。在工作台默认高度、分栏和全屏核对取景与控件位置。拖动缩放滑杆检查连续反馈，用键盘、滚轮和适应视图核对滑杆同步。从俯视点击「等轴测」返回等轴测，重复点击保持等轴测。点击向上箭头打开「选择视角」菜单。按住 Command 从滑杆或按钮拖动整组，核对画布边界和缩放值。
2. 保存一个改变过缩放的机位，切到另一个标准视图，再点机位恢复。重载浏览器后复验，确认其他场景的菜单没有该机位。
3. 在 USD 与 Markdown 中从选择器切换编辑和预览，核对同组入口唯一。用分栏预览核对两组各自显示对应方式。普通 JSON 直接进入文本编辑器。
