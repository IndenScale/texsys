# DDR-0016：资源管理器标题与活动栏右键菜单

- 状态：已接受
- 日期：2026-11-12
- 修订：[DDR-0015](0015-studio-explorer-workspace-section-and-project-root.md) 补充面板和分区菜单；[DDR-0003](0003-studio-interaction-design.md) 补充活动栏和主侧栏位置选项
- 关联：[资源管理器对照](../studio-explorer-context-analysis.md)、[工作台契约](../../spec/studio/01-workbench.md)

## 背景

资源管理器已有面板、工作区分区、项目树三个层级。用户对照截图指出，工作区标题的右键仍打开 Chrome 原生菜单，资源管理器标题没有对应的视图菜单，活动栏的菜单也没有反映点中的入口。按命中对象组织操作，同一个位置用鼠标或键盘打开时应得到相同菜单。

## 决策

| 命中位置                       | 菜单职责                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| 资源管理器面板标题及其更多按钮 | 管理资源管理器中的视图，并提供活动栏位置、移动主侧栏及隐藏主侧栏等布局操作。                       |
| 工作区分区标题                 | 管理资源管理器中的视图；文件夹视图必需，隐藏项不可用。折叠仍由分区开关控制。                       |
| 活动栏入口                     | 提供所点入口的隐藏操作；只有源代码管理入口提供徽标显示开关。随后列出所有当前支持的活动及布局操作。 |
| 活动栏空白                     | 列出活动的显示状态及布局操作，不以当前活动代替被点中的入口。                                       |

「打开的编辑器」切换资源管理器内的实际分区。该分区按编辑器组列出已打开的视图，选择条目进入对应的编辑器组；显示、隐藏和折叠分区均不关闭编辑器。文件夹分区保持独立，右键不选择项目根或文件。

活动栏可贴在主侧栏外缘，或在主侧栏展开时显示于其顶部／底部；主侧栏收起后活动栏回到可达的外缘，重新展开后恢复所选位置。主侧栏与属性面板可以交换左右位置。活动入口及徽标的可见性、栏位置和尺寸由现有浏览器布局偏好保存。隐藏当前活动时，侧栏切换到第一个仍可见的入口；全部入口隐藏时收起主侧栏。活动栏仍保留，空白处的菜单可以恢复入口。

标题、活动栏及更多按钮复用通用菜单。右键、菜单键和 Shift+F10 按同一上下文打开；Escape 关闭后焦点回到原位置或仍可操作的替代入口。菜单仅列出工作台已有的视图和可用操作。账户、大纲、时间线和快捷键编辑不在本决策范围内，文件树条目的右键也单独处理。

## 验收

对工作区标题、资源管理器标题、更多按钮、活动图标和活动栏空白分别验证菜单内容及命中目标。验证文件夹仍可独立折叠，显示或隐藏打开的编辑器时文件选择与打开文档不变。验证隐藏活动、恢复活动、徽标开关、活动栏位置／尺寸、主侧栏左右移动与隐藏后的恢复。键盘检查覆盖打开、Escape 回焦点、活动栏横竖方向导航。既有 Chrome 验收与组件行为测试分别记入工程 POC 台账。
