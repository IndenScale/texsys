# DDR-0021：状态栏贴底与空白工作区入口对齐参考工作台

- 状态：已接受
- 日期：2026-11-15
- 取代：无（修订 [DDR-0018](0018-studio-status-bar-editor-and-workbench-actions.md) 的键盘布局与图标尺寸、[DDR-0020](0020-studio-empty-workspace-full-shell-and-bare-entry.md) 的空白工作区外壳部分）
- 被取代：无

## 用户体验与交互背景

用户以 vscode.dev 的空白工作区为参照逐块核对 Tex Studio 空白工作区：状态栏应贴底且内容与参照一致；资源管理器底部应有「大纲」「时间线」节；顶部应保留可用的全局搜索入口；左下问题计数应常显且点击打开对应视图。此前状态栏随工作区卡片留 5px 底隙与圆角，呈浮层观感；问题计数在无项目时隐藏；键盘布局入口及其弹层对本地工作台没有实际用途；顶部命令中心在空白工作区被禁用。

## 设计决策与规范约束

- 状态栏可见时工作区底部间隙为 0、卡片底角改直角，内容直接落到状态栏上沿；侧栏与编辑区不再与状态栏之间露出背景条。状态栏隐藏时恢复原有卡片底隙与圆角。顶部与两侧间隙不变。
- 问题计数（错误／警告图标与计数）在空白工作区同样显示，计数为 0；点击在两种模式下都打开底部「问题」视图，空白工作区打开欢迎外壳的问题标签。
- 移除状态栏键盘布局入口及「浏览器报告的键位」弹层；「键盘快捷键参考」保留在帮助菜单与命令面板，不再占用状态栏。右端仅保留通知铃铛等既有项。
- 通知铃铛使用 16 CSS 像素，与参照工作台实测一致；其余状态栏主要图标仍为 14 CSS 像素。
- 空白工作区顶部命令中心可用，作为全局搜索／命令入口，列出空白工作区命令集；文件搜索在无项目时诚实为空。
- 空白工作区资源管理器底部增加「大纲」「时间线」两个可折叠节，默认折叠，展开显示诚实空态（打开文档／文件后可用），不伪造内容；项目模式的专业视图不在本决策内扩展。

## 备选方案

- 保留键盘布局入口以完全镜像 vscode.dev：本地工作台不存在跨键盘布局的快捷键重映射需求，弹层只增加噪声，用户明确认为没必要。
- 状态栏整体改为无卡片贴边布局：会推翻既有工作区卡片设计语言；仅消除底隙与底角即可满足参照观感。
- 大纲／时间线在空白工作区直接实现真实视图：无打开文档与文件时没有可展示内容，先以可折叠空态节对齐结构，真实视图随项目模式另行决策。

## 体验影响与权衡

收益：空白工作区与参照工作台逐块对齐，状态栏不再像额外浮层；问题入口在两种模式下行为一致。代价：状态栏可见时卡片底部直角与其余圆角形成混合轮廓；大纲／时间线在空白工作区仅为结构占位，需向用户说明其空态语义。受影响模块：外壳布局 CSS、StatusBar、WelcomeWorkspace、host 命令中心开关。

## 可用性走查与验收标准

在现有 Chrome 复用唯一实例走查：裸入口状态栏上沿无背景间隙、卡片底角直角；隐藏状态栏后恢复底隙与圆角；空白工作区左下显示 ⊗ 0 ⚠ 0，点击打开问题标签；右端无键盘布局入口，铃铛 16px；顶部命令中心可打开并执行空白工作区命令；资源管理器底部两节默认折叠、展开为空态提示。模型与服务器测试、tsc、ESLint、Prettier 通过。
