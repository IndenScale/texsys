# DDR-0007：浅色主题源代码管理与提交历史拓扑

- 状态：已接受
- 日期：2026-11-07
- 取代：无
- 被取代：无

源代码管理采用与编辑器一致的浅色主题，支持本地 Git 变更与提交历史浏览。

## 管理范围

在面板顶部可以切换“当前项目”和“整个 Git 仓库”。范围由服务端根据当前项目定位，不接受任意磁盘路径。

当前项目范围提交时，若暂存区含有项目以外的文件，会拒绝提交并提示先处理这些文件。批量暂存、取消暂存均只作用于当前列表中的文件。构建输出、内部目录和符号链接仍按工作区规则过滤。

## 变更与提交

- 单击文件查看工作区或暂存区差异；同一个部分暂存的文件会出现在两个分组中。
- 文件行悬停或获得键盘焦点时显示打开文件、放弃更改、暂存或取消暂存操作。整个仓库模式下，当前项目以外的文件通过差异视图浏览。
- 分组右侧的加减号用于批量暂存或取消暂存，分组可折叠。
- 填写提交说明后点击“提交已暂存的更改”，或在输入框内按 Command/Ctrl + Enter。最多支持 4000 字符。
- 放弃更改前显示确认提示。已跟踪文件恢复为暂存区版本，未跟踪文件从磁盘删除。此操作也会关闭对应文件的未保存编辑。
- 操作使用状态快照校验；外部修改后，过期请求被拒绝。暂存与提交使用磁盘内容。

## 提交历史图

历史图显示整个仓库所有分支的真实提交父子关系，以及作者、分支或标签；悬停查看提交时间和完整哈希。点击提交，在编辑区查看该提交在当前管理范围内的差异。合并提交以第一父提交为差异基准。

初次加载 50 条，可继续加载至 500 条；文本差异最大显示 1 MiB，并明确标记截断。尚无提交、加载失败及无范围内差异分别显示提示。

## 验证

本次定向验证通过 44 项 Studio 后端测试、22 项前端模型测试及 TypeScript 类型检查。

后端测试覆盖真实临时 Git 仓库中的批量操作、部分暂存、删除、重命名、初次提交、范围隔离、状态过期、历史拓扑、接口授权及历史差异。前端模型测试覆盖合并提交图的分支汇合关系。

Google Chrome 中使用临时仓库验证了批量暂存、快捷键提交、历史自动更新和历史差异浏览。验收提交仅创建在临时仓库中。
