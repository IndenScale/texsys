# DDR-0031：对标 VS Code 开源实现的智能体面板与双层输入区

- 状态：已接受
- 日期：2026-11-18
- 取代：部分修订 [DDR-0030](0030-studio-agent-panel.md) 的标题栏动作、会话列表、欢迎页智能体单选墙、单行输入栏与工具卡片输出展开；右侧专职面板职责与双工作区隔离继续有效
- 被取代：部分由 [DDR-0032](0032-studio-agent-panel-grid-and-model-sliders.md) 修订（顶部与输入区双层同尺度网格对齐、移除顶部重复会话切换按钮、ChatGPT 风格双滑块模型调节与按 Provider 堆叠的模型目录）

## 用户体验与交互背景

对照真机运行截图与 VS Code 开源聊天视图（`src/vs/workbench/contrib/chat/browser/`），DDR-0030 首版界面暴露出多项结构缺陷：

1. **右侧容器缺少导航内边距变量**：`.workbench-inspector` 未声明 `--navigator-gutter` 与 `--navigator-end`，面板标题「智能体」和关闭按钮紧贴左右 1 px 边框。
2. **单行输入底栏在窄侧栏下挤爆**：将 Harness 名称、模型下拉、推理强度下拉、上下文百分比和发送按钮全部塞进同一行后，320 px 默认宽度下「DeepSeek Harness」折成两行，发送按钮被挤出容器右侧并裁切；原生 `<textarea>` 的 `resize: vertical` 右下角斜纹手柄与底栏文字重叠。
3. **欢迎态堆砌配置噪音，会话中又锁死 Harness**：空白会话在对话区中央铺满未安装 CLI 的单选卡片与配置文件路径提示；一旦进入会话，底部 Harness 变成静态文本，无法直接切换运行环境。
4. **工具原始输出与 Markdown 排版失真**：DeepSeek Harness 等仅通过 `rawInput`／`rawOutput` 回传结果的 ACP 智能体未填充 `content` 块，导致 `bash` 工具卡无法展开查看完整命令与标准输出；回答区列表沿用文档预览的 `2em` 缩进且行内 `<code>` 缺少断词规则，中文词组在路径前被生硬拆行。

## 设计决策与规范约束

### 1. 面板标题栏与最大化控制（对标 `chatViewPane` 与 `chatNewActions`）

- 标题栏左侧将「智能体」渲染为活动视图胶囊标签，补齐右侧面板的水平内边距变量，支持在标题栏空白处右键呼出面板操作菜单。
- 右侧操作栏依次为：处理中脉动圆点、`+ ⌵` 分段新建会话按钮（主按钮立即新建会话，下拉菜单列出「新建会话」及各已注册 Harness 的直接新建入口）、`◫` 切换会话列表按钮、`⋯` 更多操作菜单、竖向分隔线、`⛶` 最大化／还原面板大小按钮与 `✕` 关闭面板按钮。
- `⋯` 更多菜单对标 VS Code 视图菜单，提供新建与关闭会话、在源代码管理中审查修改（或空白工作区打开项目）、「视图模式」子菜单（显示会话栏、紧凑工具卡片）、「智能体配置…」、刷新智能体列表、「显示智能体调试日志」开关与「默认显示视图」重置入口。

### 2. 会话副栏与会话标题导航（对标 `chatViewSessionsList` 与 `chatViewTitleControl`）

- 空白态或展开会话抽屉时显示 28 px「会话」副栏，提供会话计数徽标及刷新、搜索、状态筛选（全部／进行中／已结束）与收起入口；会话行采用双行结构（标题＋悬停关闭按钮，次行显示 Harness 图标、名称与状态）。
- 会话进行中且收起列表时，副栏切换为紧凑会话标题条（`← Harness · 会话标题`＋状态胶囊＋展开会话列表），点击返回即可在不销毁后台会话的前提下回到新对话。

### 3. 叠栈式输入区与双层工具栏（对标 `chatInputPart`、`TabbedModelPicker`、`SessionTypePicker` 与 `PermissionPicker`）

- **叠栈顶部工作集（Docked Working Set）**：当智能体修改了项目文件时，「智能体修改了 N 个文件」与「审查修改」入口以共享圆角叠接在输入框正上方，形成单一输入栈表面，仍不设接受／拒绝工程变更按钮。
- **输入框本体**：移除原生 `resize` 斜纹手柄，按内容在 40–180 px 间自适应增高；占位符精简为单行省略文本；处理中围绕输入框呈现柔和流光进度描边（遵守 `prefers-reduced-motion`）。
- **框内主工具栏（22 px 控件层）**：
  - 左侧依次为 `+` 添加上下文浮层（支持搜索并多选最多 16 个项目文件，及切换当前活动文件）、`✨` 模型选择器（宽度充裕时显示可收缩省略的「模型 · 推理摘要」，绝不挤压右侧按钮）与 `⇄` 推理配置及斜杠命令浮层。
  - 点击 `✨` 打开对标 `TabbedModelPicker` 的模型浮层：顶部显示 Harness 标签、`+` 配置入口与 `🔍` 搜索过滤框；列表展示可选模型与所属 Harness（同时兼容 ACP `configOptions` 模型项与 `models`／`session/set_model`），底部提供推理强度等非模型配置分段按钮。尚未建立会话时打开浮层将自动预热连接以拉取真实模型列表。
  - 右侧固定不收缩（`flex: 0 0 auto`）：上下文用量环形进度指示器（14 px 圆环＋百分比，点击查看精确 token 用量）与 22×22 px 圆形 `↑` 发送／`■` 停止按钮。
- **框外次级工具栏（`.agent-secondary-toolbar`）**：
  - 左侧第一个胶囊为 `[🖥 Harness]` 运行环境选择器（对标 `SessionTypePickerActionItem`），随时可切换已安装的 ACP 智能体，底部提供「了解与配置智能体 Harness…」入口按需展开 `studio-agents.json` 配置卡片。
  - 第二个胶囊为 `[🛡 默认权限]` 权限与模式选择器（对标 `PermissionPickerActionItem`），提供「默认权限（每次询问）」与「自动允许（本会话自动批准工具授权请求）」双行说明项、智能体声明的 ACP `modes` 切换，以及当前工作区隔离边界说明。

### 4. 对话呈现与调试视图

- 欢迎态在存在可用智能体时保持安静留白，仅在无可用智能体、存在配置诊断错误或用户主动打开「智能体配置…」时展示配置说明卡与可复制 JSON 示例。
- 工具调用卡在无 `content`／`terminal` 块时回退解析 `rawOutput` 文本，并对命令行工具始终支持展开查看完整换行命令与输出。
- 回答区列表缩进收紧至 `20px`，列表内代码块反向抵消缩进以占满可用宽度，行内 `<code>` 允许断词换行；每条回答底部在悬停或最新完成态显示复制按钮与模型署名；上滚离开底部时浮现「滚动到底部」圆形按钮。

## 体验影响与权衡

- 模型与推理配置在首次打开浮层且无会话时会触发智能体子进程预热，换取发送首条消息前即可查看和切换模型。
- 「自动允许」仅自动应答当前会话内的 ACP `session/request_permission` 工具授权，不改变后端强制执行的工作区路径边界，也不构成工程设计接受。

## 可用性走查与验收标准

1. 在 280 px（最小宽度）、320 px（默认宽度）和最大化三种宽度下检查输入区：圆形 `↑` 发送按钮、环形上下文用量及下方 Harness／权限胶囊完整可见，无文字重叠或原生拉伸手柄。
2. 点击 `+ ⌵`、会话副栏筛选与搜索、`✨` 模型搜索浮层、`🖥` Harness 浮层、`🛡` 权限与模式浮层及 `⋯ → 显示智能体调试日志`，键盘 Escape 与外部点击均可关闭浮层。
3. 对仅返回 `rawInput`／`rawOutput` 的 `bash` 工具卡片点击展开，确认完整命令与输出可读；长路径行内代码不拆断前导中文词组。
