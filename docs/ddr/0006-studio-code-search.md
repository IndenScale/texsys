| 原有偏差                                                       | 当前实现                                                             |

## 真实操作与范围

搜索由宿主 `CodeSearch.tsx` 提供，专业扩展不拥有搜索状态。切换侧栏保持查询和折叠状态。结果摘要、侧栏树和中央文档共享当前搜索，文件内容继续通过通用 Editor 打开；替换涉及的已打开干净文件会重新读取，未保存文件先要求处理草稿。

搜索 API 同时返回独立匹配与按行组织的结果，避免界面用重复行伪装为多条行结果。服务端列号按 Unicode 字符计数，前端高亮保持完整字符，跳转时转换为 Monaco 文档的 UTF-16 偏移。

替换支持全部匹配或单个文件。点击替换先展示文件、数量和首处修改前后片段；确认执行时校验预览快照和文件版本。替换表达式支持 `$1`、`${name}`、`\n`、`\t`，并可保持原匹配的全大写、全小写或首字母大写形式。每个文件使用既有原子保存机制，保留换行和 BOM。多文件执行中失败时明确报告已完成文件，不能声称整个批次具有文件系统事务原子性。

搜索仍限定在当前项目，排除构建产物、版本库内部文件、依赖缓存与符号链接。单文件文本限 1 MiB，扫描限 32 MiB，最多 1000 处匹配；截断时不允许全部替换。正则为 Python 表达式，在独立短生命周期进程中执行，2 秒超时，最多两个并行任务。空宽度匹配不会生成无法选中的结果行。

## 颜色、字重与缩进复核（2026-11-07）

本轮按 Explorer 的固定槽位方案修复 Code Search。保留浅色工作台，搜索文字使用独立的中性色语义，不直接照搬深色参考图的 RGB 值。参考图只能用于判断视觉层级；下列字重为本项目的明确实现值。

| 偏差来源                                                         | 修复与 Chrome 实测                                                                          |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 搜索文字继承工程工作台的蓝灰 `#263b46`，标题、文件与正文层级混用 | 正文 `#424242`，次要说明 `#757575`，工具图标 `#707070`；链接与输入焦点使用蓝色              |
| 搜索标题单独设置字体与边距，切换内置 activity 时标题位置变化     | 三个内置侧栏标题共享系统 UI 字体、13px 字号和 600 字重；搜索标题与输入框距侧栏左缘均为 20px |
| 文件名额外使用 500 字重，字体链与系统编辑器不一致                | 搜索范围使用系统 UI 字体；文件名与结果正文均为 13px、400 字重                               |
| 文件行依赖零散 gap 和 padding，没有固定箭头／图标槽              | 复用 Explorer 的 8px 基准与 16px 固定槽；文件名从 96px 调整为 92px，文件行高 24px           |
| 搜索预览保留源码前导空白，嵌套越深看起来缩进越大                 | 仅展示时移除匹配以外的前导空格和 Tab；各结果文本均从 82px 开始，真实 Unicode 列号保留       |
| 结果行的 line-height 加上下 padding，使预期行高被撑开            | 固定 22px 结果行，去除上下 padding；匹配高亮使用低饱和度底色                                |

- 展开状态的省略号并入“包含文件”标签行右侧，不再单独占 22px 高度；折叠开关仍可通过键盘操作。

- 搜索操作使用独立的 16px、1px 描边图标：去除文档折角加号、密集双向替换箭头等细节；替换图标使用单向箭头。共享工作台图标未被修改。
