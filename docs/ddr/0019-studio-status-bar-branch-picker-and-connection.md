# DDR-0019：状态栏分支选择与连接恢复

状态：已接受

修订 [DDR-0018](0018-studio-status-bar-editor-and-workbench-actions.md) 的分支和宿主入口，以及 [DDR-0007](0007-studio-source-control.md) 的 Git 签出范围。

点击状态栏分支名，在顶部命令中心搜索并签出本地分支、远程跟踪分支和标签。选择器提供从当前提交创建分支、从指定引用或提交创建分支，以及分离签出。引用行显示提交作者、时间、短哈希和说明，标记当前分支。配置 GitHub 远程时，可从引用行打开 GitHub 或 vscode.dev。

打开和取消选择都保留活动侧栏和文档，Esc 将焦点还给分支按钮。源代码管理活动继续承载变更和历史。

签出作用于项目所在的 Git 仓库。远程跟踪分支复用对应的本地跟踪分支，或创建新的本地跟踪分支。存在未保存的文件时先处理编辑；已写入磁盘的更改遵循 Git 的普通切换保护。目标提交须保持与当前工作台兼容的项目清单。

正常连接时，本地 Web 工作台省略远程窗口入口；工作台无法读取本地服务时，状态栏提供直接重试。空白工作区仍通过「文件 → 新建窗口」打开。
