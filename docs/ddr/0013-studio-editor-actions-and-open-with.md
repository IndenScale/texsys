# DDR-0013：编辑器操作栏、打开方式与分栏预览

- 状态：已接受
- 日期：2026-11-11
- 取代：部分修订 [DDR-0012](0012-studio-file-preview-and-source.md) 的视图切换入口；统一文件组件和仅替换预览实现的约束继续有效
- 被取代：无
- 关联：[DDR-0005](0005-studio-core-editor.md)、[ADR-0028](../adr/0028-file-based-artifact-preview.md)

## 背景

文件已经共享编辑与预览框架，但「预览 / 源代码」两个按钮把打开方式固定成两种状态，不能清楚表达文件可用的编辑器与预览器。编辑器标签操作栏需要直接提供常用的预览和分栏入口；「与磁盘比较」不应占据这里的常驻按钮位置。Markdown 的分栏预览应保持普通编辑器组的行为，让用户分别切换和关闭左右文档。

## 决策

### 编辑器标签操作栏

- 删除编辑器标签操作栏中的「与磁盘比较」按钮。文件的版本冲突与磁盘内容比较继续遵循通用编辑行为，不因此另建工程变更界面。
- Markdown 文本编辑器的操作按钮按「预览、分栏预览、分栏、更多操作」排列，按钮只显示图标，名称通过提示和无障碍标签表达。预览模式提供「源代码、分栏、更多操作」。
- 「预览」在当前编辑器组中使用该文件的预览器打开；「分栏预览」在相邻编辑器组打开同一文件的预览，保留当前组；「分栏」在相邻编辑器组打开当前文件及其打开方式。
- 「更多操作」使用通用编辑器菜单。文件格式与专业扩展不再为这些操作增加第二套工具栏。

### 打开方式选择器

- 文件路径导航右侧使用「打开方式」选择器，替代「预览 / 源代码」双按钮。选择器显示当前方式，菜单标识当前选中项。Markdown 提供「文本编辑器」「Markdown 预览」「Markdown Editor」三种实际实现的打开方式。
- Markdown Editor 提供面向 Markdown 的可编辑视图，使用同一文件源文本和保存能力；不能把只读预览更名后作为编辑器。它与文本编辑器、预览共用文件组件，不增加专用文档布局。
- 尚未设置个人默认值时，Markdown 首次打开使用文本编辑器，图纸与场景保留默认预览方式。显式的预览、分栏预览和打开方式切换优先于默认值。
- 菜单只列该文件实际支持的方式。普通 JSON 使用文本编辑器；有预览器的文件可选择对应预览。不可用的打开方式不得保存为该文件的默认方式。
- 即使只有一种可用方式，也保留一致的选择器形态。选择器采用工作台的下拉菜单，支持键盘操作、Escape 和点击外部关闭，不弹出模态选择窗口。
- 切换打开方式只改变当前组中该文档的呈现，不改变文件身份、路径、内容或未保存状态。源代码的名称仍为「源代码」，不得重新使用「原始内容」。

### 文件类型默认值

- 打开方式菜单提供「为「*.md」设置默认值」子菜单，按当前文件的真实扩展名显示，例如 `*.md` 与 `*.markdown` 分别设置。子菜单列出同样可用的打开方式，并标识当前默认值。
- 默认值是当前浏览器的个人偏好，以小写扩展名保存，跨页面重载和会话保留；同源页面通过偏好存储通知同步。不写入项目依赖或设计文件。
- 修改默认值只影响之后新开的文件视图，不强制切换已打开的视图，也不改变它们的编辑内容。手动切换当前视图不隐式改写文件类型默认值。
- 未知、损坏或该文件不支持的偏好回退到该格式的默认方式。即使图纸 JSON 设置了预览默认值，普通 JSON 也继续使用文本编辑器；Markdown Editor 只适用于 Markdown。

### 分栏与共享文档

- 分栏使用通用编辑器组。每组有自己的标签、当前文档、打开方式和关闭操作，用户可以在左右组分别切换源代码与预览，或打开其他文件。
- 同一路径只对应一份共享文件内容、保存基准及未保存状态。多个组查看同一文件时，源代码或 Markdown Editor 的编辑立即反映到其他视图，预览读取当前编辑内容。任一组保存后同步更新所有视图的未保存标记。
- 关闭一个视图不得关闭另一组的同文件视图，也不得丢弃共享编辑。只有关闭该文件的最后一个视图时，才按通用规则处理未保存内容；组为空时收起该组。
- 打开方式选择器、标签操作栏和分栏能力属于通用文件组件。Markdown Editor 替换文件内容区的编辑实现；Markdown、图纸和场景预览仍只替换预览区域的实现，不改变文件布局，不增加产物标题、构建状态或专用 Activity。

## 取舍与边界

打开方式说明当前文件如何呈现，分栏说明文档放在哪个编辑器组，文件类型默认值决定后续新视图的初始方式。三者分别操作。共享文档避免在左右组形成两份独立草稿，但需要统一处理保存、外部变化和关闭最后一个视图。Markdown Editor 编辑当前 Markdown 文件，不改变源文件的保存接口，也不引入图形预览反向写回声明式设计的能力。

## 验收标准

以下为实现与走查要求，不代表已完成验收：

1. 在既有 Google Chrome 工作台首次打开未设置默认值的 Markdown，显示文本编辑器，标签操作栏不存在「与磁盘比较」按钮，四个按钮按规定顺序显示且具有可辨识的提示。
2. 路径导航右侧只有统一的打开方式选择器；Markdown 可以在文本编辑器、Markdown 预览和实际可编辑的 Markdown Editor 间切换，普通 JSON 不出现虚构预览或编辑器。
3. 分栏预览后两侧拥有独立标签与打开方式。分别切换、关闭一侧或在一侧打开另一文件，另一侧文档不被连带关闭或替换。
4. 同文件两侧源代码与预览共享当前内容和未保存标记；从任一侧保存后核对文件落盘及两侧状态。关闭其中一侧保留草稿，关闭最后一个视图才处理未保存内容。
5. 切换方式、分栏与关闭不改变统一文档布局，不出现额外的运行 ID、缓存、目标判定或只读状态条。外部文件变化继续遵循既有版本冲突处理，不覆盖未保存内容。
6. 设置 `*.md` 默认方式后，当前视图保持原方式，新开 Markdown 采用新默认值；页面重载后重新打开仍采用该默认值。普通 JSON 遇到不适用的偏好仍使用文本编辑器，损坏存储可恢复格式默认值。

## 参考
