# DDR-0028：源代码管理复用 Activity 面板布局

- 状态：已接受
- 日期：2026-11-16
- 修订：[DDR-0007](0007-studio-source-control.md) 的范围入口和历史区域布局，以及 [DDR-0005](0005-studio-core-editor.md) 的折叠拖动规则。

## 决策

- Activity 复用通用面板外壳。源代码管理和资源管理器的可调整分区使用同一个分隔把手，支持拖动、方向键、Shift 加速和双击恢复默认。
- 从已折叠分区拖动时，按下只取得指针控制。沿可展开方向移动后，主体从零开始按位移展开。反向拖动维持折叠，拖回起点恢复原布局。松手保留实际高度，包括短距离拖出的高度。直接单击标题仍按上次高度展开。
- 拖动把手收缩分区时，主体可以连续缩到零。到达或超过该边界即收起，只显示标题。拖出边界后再往回拉，可以在同一次拖动中重新展开。收起保留该分区拖动前的高度，供单击标题时恢复。方向键沿用同一边界规则。
- 源代码管理标题的「…」及右键菜单列出「存储库」「更改」「图谱」三个视图。存储库默认隐藏，更改和图谱默认显示并展开。两者都展开时默认平分可用高度，工作区变更增减不改变分区高度或展开状态。
- 展开存储库卡片后，在仓库行切换「当前项目」与「整个仓库」。卡片显隐只改变布局，保留当前选择。每次打开工作台以当前项目范围开始。
- 视图显隐和调整后的图谱高度随项目布局保存。更改和图谱各自滚动。收起或隐藏其中一项时，展开的另一项使用余下空间。
- 图谱仍读取仓库历史。更改列表、暂存操作与打开提交后的差异沿用选择的文件范围。

## 验收

用父仓库内的工程项目切换管理范围，核对仓库范围显示项目外的变更，切回项目范围后只显示项目内变更。分别核对两区的拖动、键盘调整、双击恢复、菜单显隐及重载还原。文件变更和历史提交继续在编辑区打开 Git 差异。折叠时核对按下、微拖、回到起点和松手的实际分隔线坐标，并在资源管理器的大纲与时间线上重复。检查两侧边界前 1 px、越界、反向撤回折叠及松手确认。
