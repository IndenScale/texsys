## 标题栏

标题栏高 40 px，使用与工作台一致的纯色表面，不放品牌文字、Logo 或模拟窗口按钮。当前 Web 宿主最左侧显示应用菜单，右侧相邻的固定区域提供后退、前进、资源面板、底部面板、属性面板五个按钮。只有实际使用左侧原生窗口控件的宿主才保留 88 px 控件区。

标题栏按钮统一使用 `ToolbarButton`：32 × 32 px 点击区、18 px 图标、7 px 圆角，组内间隔 2 px，导航与面板组相隔 8 px。图标移除无必要的小短线，面板开闭通过分隔线的位置与长度表示，不使用填充或额外的选中色。默认无边框；悬停和按下分别使用轻重两档中性底色；键盘焦点保留 1 px 内收灰线，不沿用全局绿色描边。鼠标点击不强制显示焦点框。

提示在停留约 550 ms 后出现，操作名与已生效的快捷键分区显示。点击、移出或 Esc 收起提示；键盘聚焦也可读取提示。尚未绑定的快捷键不显示。命令入口采用下述 Hanging 复合控件规则。

中央只显示项目名称，正常工作台宽度下按整个窗口居中。标题采用 13 px、500 字重与更深的中性色，视觉权重高于工具图标。点击打开统一搜索；`⌘/Ctrl+P` 选择“文件”，`⌘/Ctrl+Shift+P` 选择“命令”。左右侧栏开闭不改变标题位置。只有右侧使用原生窗口控件的宿主才保留相应区域。

后退与前进使用各专业的文档访问历史，不操作浏览器历史。无可用历史时禁用；回退后打开新文档会截断前进历史。已关闭文档可以从历史重新打开。Activity 切换与对象选择不生成文档历史。

右键标题栏，或聚焦标题栏控件后按 Shift+F10，可打开「配置标题栏」菜单。三个组件组分别为命令中心（Command Center）、导航控件（Navigation Controls）和布局控件（Layout Controls），默认全选。勾选状态保存在当前浏览器中并跨项目复用。取消勾选命令中心后，项目名以相同位置、字号和字重继续显示，点击入口收起，搜索快捷键仍可用。隐藏布局控件后仍可从「视图」菜单切换面板。

## 菜单命令归属

`src/texsys/assets/studio/menus.ts` 定义平台无关的菜单模型和稳定命令 ID。当前命令面板使用同一模型，支持筛选、方向键、Enter、Esc、禁用状态及焦点恢复。

应用菜单与命令中心共用命令处理、可用状态、布局勾选及独立快捷键键帽。菜单与可见的导航和布局控件紧邻，中间只保留 12 px 分组间距，不插入弹性空白。两组同时显示时占 174 px，隐藏一组后腾出的空间让给应用菜单。菜单预算从左侧区域总宽度中扣除可见控件、窗口控件预留、内边距和分组间距。只有完整菜单确实放不下时，才按实际文字宽度从右向左收进“更多”，并计入“更多”自身宽度；折叠后保持原顺序。窗口重新变宽后自动恢复可见菜单；正常宽度下中央命令入口保持窗口居中。

一级菜单由点击展开，再次点击收起，点击其他一级菜单切换。鼠标移过一级菜单只提供 Hover 反馈，不打开或切换菜单。二级菜单可悬停展开，也可点击或用右方向键进入。F10 聚焦菜单栏，左右键切换顶层菜单，上下键浏览条目，Enter 执行，Esc 逐级返回并恢复焦点；禁用命令不执行。点击外部或窗口失焦关闭；窗口尺寸改变时收回菜单并重新计算可见项。

小于 560 px 的极窄窗口中，菜单按可用空间归入“更多”，已勾选的导航和布局控件完整保留，命令入口使用剩余区域。激活搜索时使用窗口可用整宽。

| 菜单 | 命令归属                                                                                             |
| ---- | ---------------------------------------------------------------------------------------------------- |
| 文件 | 新建文本与项目文件、打开与最近文件、新建窗口、保存／另存为／全部保存、自动保存、还原、设置与关闭确认 |
| 编辑 | 当前源文件的撤销、重做、查找与替换                                                                   |
| 查看 | 命令面板、工作台视图、面板布局、问题、任务与日志                                                     |
| 转到 | 快速打开文件、后退、前进、项目概览                                                                   |
| 运行 | 当前专业提供的工程操作、取消当前后台任务                                                             |
| 终端 | 新建或拆分会话，在终端运行活动文件、选定文本或 `texsys build`                                        |
| 帮助 | 专业能力与范围                                                                                       |

暖通专业在「运行」提供模型检查、生成图纸和仿真。检查和出图复用专业工具栏的提交行为，仿真入口先打开工况和求解后端的配置界面。任务日志通过「查看」打开，终端命令作用于 Shell。菜单始终从 Web 标题栏左侧展开；Activity Bar 继续用于切换工作台视图。

命令统一称为「文件 → 新建窗口」。Web 宿主在当前浏览器窗口中打开一个空白工作区标签页，桌面宿主应打开一个原生窗口。空白工作区显示资源管理器的「无打开的文件夹」状态，并在「欢迎」编辑器标签中提供「启动」「最近」和「演练」。Chrome 授权后，用户可打开本地文件夹、编辑和保存 UTF-8 文本；最近使用的文件和文件夹保存在浏览器中。刷新回到欢迎页，不自动恢复文件夹或打开工程。用户选择「打开已启动的项目」后，当前标签页才加载本地 Studio 服务所绑定的工程。

## 状态栏

底部左侧按项目 → 专业 → 分支排列。项目与专业菜单保留实际行为并向上展开；分支为只读身份。连接、工程审核、输入修订与运行状态在右侧紧凑显示，窄窗口隐藏次要状态，不隐藏工作上下文。

## 宿主能力与边界

当前代码是本地 Web 宿主，没有 macOS 桌面壳及原生菜单绑定。Web 包括 macOS 上的 Chrome，均显示应用菜单，不把浏览器的系统菜单误作工作台菜单。

`startStudio(plugins, chrome?)` 接受可选宿主能力：`nativeMenu` 与 `windowControls`（external / left / right）。默认是 Web 的应用菜单及外部窗口控件，不根据操作系统猜测。只有宿主实际提供本应用原生菜单时才声明 nativeMenu；原生绑定应复用当前命令 ID、可用状态和处理逻辑。此适配入口不代表已经交付或验收 Windows、Linux 或 macOS 原生宿主。

## Hanging Command Center

选用 Hanging。标题、输入与结果属于同一个持久挂载的 `CommandCenter` 控件。

1. 默认显示项目名；悬停或键盘聚焦时直接呈现完整输入框的外观与提示文字。交互命中区与最终输入宽度固定，Hover 的可见外框从项目名区域向两侧展开。
2. 点击标题进入“全部”，`⌘/Ctrl+P` 选择“文件”，`⌘/Ctrl+Shift+P` 与 `commands.open` 选择“命令”；各入口均使用同一控件：项目名隐藏，标题栏原位出现并聚焦命令输入。
3. 输入框与结果列表同宽、同轴、直接相连，列表从输入框下沿展开。展开宽度最多 560 px，受左右窗口控制区域约束，不覆盖导航与布局按钮。
4. 不创建独立 dialog、全页遮罩或第二个搜索输入。主工作台保持可见且可交互。
5. 方向键选择、Enter 执行，执行后恢复项目标题；无匹配项时 Enter 不执行任何命令。
6. Esc 恢复项目名并返回唤起前的控件。Tab 可正常离开，不困住键盘焦点。外部点击关闭且继续执行点击目标，不抢回焦点。
7. 已展开时再次按快捷键聚焦并选中当前输入，不创建第二个面板。中文输入法组合期间的 Enter 不执行命令。

菜单命令使用共享处理入口；当前仍未安装原生系统菜单。关闭后清空本次查询，不改变工程模型或参数草稿。

## Codex 风格的命令列表

保留 Hanging，采用小圆角：输入框和下挂列表外轮廓 6 px，当前行 4 px。采用浅色中性表面、轻轮廓和柔和阴影，当前行的灰阶对比高于悬停行。

命令名采用 13 px 正文和 32 px 行高，是主要扫描对象。左侧使用 16 px 图标槽，输入内容与候选名称共用起点；类别、实际已绑定的快捷键和面板开关状态位于右侧固定辅助列，桌面列宽为 44 / 88 / 14 px，列间距 8 px。每个按键独立渲染为键帽，间距 3 px。分组入口位于列表底部，为“全部 / 命令 / 文件”；不再显示顶部组标题。输入内容在标签间保留。

鼠标悬停不修改键盘当前项，点击执行指针目标，Enter 执行当前项。禁用态作用于整行，方向键跳过不可用命令。面板开关图标继续以分隔线位置表示状态，不引入填充。有标题栏常驻入口的布局命令不出现在空查询的默认列表；搜索“布局”“侧栏”或操作名称时仍可检索。

标题 Hover 时，输入框外框以窗口中心为锚点，从项目名宽度加两侧留白横向展开至完整宽度；移开时从两侧向中心收窄。双向时长均为 380 ms，采用 cubic-bezier(0.4, 0, 0.2, 1)，慢起步、中段加速、末段减速。高度和纵向位置固定，文字不移动或缩放，命中区保持稳定；搜索内容随外框水平揭示与收回。空间连续性、拖动吸附、画布相机与减少动态效果遵循 [工作台空间与动效准则](0003-studio-interaction-design.md)。

Hover 外观保持中性色；点击或快捷键激活后，中间实际的 input 元素使用 1 px 蓝青色强调描边和纯净输入表面，高度 24 px、小圆角 3 px。搜索图标、Esc 及外层容器保持中性，不被包入焦点框。高亮由 input 的 focus 状态控制，失去输入焦点即撤掉；文字起点与 Hover 提示及候选名称保持对齐，不改变候选行的中性选中底色。

移除视觉上的常驻操作说明栏，键盘提示通过输入框的辅助描述保留。文件标签对当前项目的文件名和相对路径进行匹配，支持模糊字符检索；Enter 或点击打开中央只读预览。构建输出、依赖缓存和越界链接不进入索引。大文件和非 UTF-8 文本明确显示预览边界。

`⌘/Ctrl+P` 是统一搜索的“文件”标签快捷入口，不创建新窗口或第二套搜索组件。快捷键在已展开时切换标签并聚焦当前输入框。文件预览复用工作台中的一个预览标签，打开其他文件时更新该标签，原设计文档仍可切回。
