# 当前范围：暖通冷启动

> 状态：有效。本文是判断"某件事是否在范围内"的权威依据。
> 范围变化必须走 ADR 或修改本文，不允许在讨论中默认扩张。

## 为什么先做暖通

暖通是少数同时具备以下条件的设计场景：

- 系统结构以**连接关系**为主，几何精度要求相对宽松；
- 元件种类有限、数量少，可控地穷举与验证；
- 评价目标（散热、通风、结露）可以用较粗的近似模型表达，且失败后果可观察；
- 现实反馈容易获得，能校准模型，而不是只能相信仿真。

这意味着暖通可以作为 SDL 的**第一个可证伪载体**，而不必等到通用语言完备。

## 范围内

1. **系统图与原理图**：系统图表达组成与拓扑（设备、管路／风管、端口连接、介质与流向）；原理图在其上增加行为定义与关键参数。两者都是模型的投影，见 [SDL 核心模型](../spec/sdl/01-core-model.md#交付物与视图)。
2. **调度（作为运行期消费方）**：调度本身属运营侧，不进入设计模型，见 [ADR-0002](adr/0002-design-time-vs-operation-time.md)。本期只做"使设计模型可被调度消费"所必需的表达：稳定身份、可寻址部件、能力参数、拓扑与介质。
3. **布置位置**：设备在空间中的相对位置与所处分区，粗粒度即可。
4. **环境条件**：设备周围的散热、通风、结露风险，作为**近似的环境约束与评价输入**，不追求精确场解。
5. **集总参数动态行为**：联立管网压力／流量、热容量、载荷与控制曲线，模拟概念工况演化，显式检查数值误差与守恒；不等于高保真瞬态。
6. **依据与证据**：每个结论关联依据版本、假设、评估器版本和证据强度。

## 范围外（当前明确不做）

- 精确制造几何、加工图、施工图深化；
- 水力/热力的高保真瞬态仿真；
- 多专业协同（结构与暖通的碰撞协调）；
- 大规模系统（数百以上元件）的性能与可扩展性；
- 施工顺序、造价、运维流程的完整闭环；
- 通用行业建模：本期不追求对其他专业的普适性。

范围外的能力可以在语言中留有扩展位置，但**不得**为未来的普适性牺牲当前可验证性。

## 精度与规模假设

| 维度       | 假设                       | 后果                              |
| ---------- | -------------------------- | --------------------------------- |
| 几何误差   | 容忍厘米级到分米级偏差     | 不要求精确 B-rep 度量作为唯一依据 |
| 环境模型   | 近似、分区、稳态及集总动态 | 结论必须标注模型与适用条件        |
| 元件数量   | 数十级                     | 允许朴素算法与全量重算            |
| 拓扑复杂度 | 中小规模网络               | 允许穷举与人工复核                |

**误差可接受不等于可以不标注。** 精度宽松只降低实现难度，不降低对"结论来自哪个模型、误差多大"的要求。

## 技术栈容忍度

早期允许场景（几何内核、Schema、依赖版本）不稳定，靠两条纪律控制风险：

1. **最小回归集**：任何被依赖的能力都要有一条可重跑的验证用例（创建、往返、度量、失败状态）。
2. **失败必须可见**：不允许"操作返回成功"被当作"结果正确"。

超出这两条的不稳定不可接受；在此之内的不稳定，可以用替换实现解决，不必提前抽象。

## 验收：什么算跑通

当前已实现与待验收项见 [项目进度审查](progress.md)。系统图／原理图已有单页根网络出图切片，协议见 [构建契约](../spec/build/03-system-schematic.md)。概念示例与自动回归不等于下列真实工程完整验收。

参照《设计自动化原理》第一章 1.6 的最小闭环与第十三章 13.6 的分阶段能力，暖通冷启动的完成标准是：

1. 一个真实小系统能被完整描述（原理图 + 粗布置 + 环境条件）；
2. 静态校验能给出**状态化**结果（通过／失败／无法判断），而不是空值或异常；
3. 至少一个环境评价器产出带依据与适用条件的证据；
4. 整条链路可重跑并得到一致结果；
5. 至少一个人工批准点被显式记录。

这五项之外的任何"演示效果"都不计入验收。
