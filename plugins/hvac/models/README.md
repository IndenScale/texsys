# 设备模型（models）

每个设备类型是 SDL 的一个 **Component 定义**；它不描述"这台泵在哪里"，只描述"这类泵是什么、有哪些端口、能力如何"。

## 单个设备类型必须包含

| 字段 | 说明 | 例 |
|---|---|---|
| `id` | 稳定身份，与厂商型号解耦 | `hvac.chiller.centrifugal` |
| `参数` | 名称、类型、单位、范围、可自动调整性 | 制冷量 kW、进出水温 ℃ |
| `端口` | 类型、方向、介质、口径、连接数限制 | `chilled_supply` DN150 水 |
| `能力` | 参数之间的关系或曲线引用（用于评价，不用于几何） | 部分负荷率—COP |
| `适用条件` | 该模型在什么范围内可信 | 蒸发温度 3–12 ℃ |
| `来源` | 依据的位置 | `暖施-02 序号 3` |

## 规则

1. **类型与实例分离。** 同一型号的 3 台泵是 1 个 Component 定义 + 3 个 Instance，不得复制 3 份定义。
2. **参数带单位。** 单位进语言，不进命名约定。
3. **能力关系不等于仿真。** 曲线只用于评价近似，必须附适用条件。
4. **未确认值显式标记。** 图纸识别不确定的参数写"已知但未确认"，不写默认值。
5. **不写入厂商专有型号作为身份。** 型号是参数，身份是类型。
