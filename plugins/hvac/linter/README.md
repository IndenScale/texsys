# 静态规则（linter）

对 SDL 描述做**不依赖求解**的检查，输出必须是状态化结果：`通过`、`失败`、`无法判断`。

## 规则清单（初稿）

| 编号 | 规则                                                                  | 级别     | 依据                                                        |
| ---- | --------------------------------------------------------------------- | -------- | ----------------------------------------------------------- |
| L001 | 每个 Net 必须显式声明，且至少包含 2 个成员 Port                       | 失败     | [OQ-3](../../../docs/open-questions.md)，冷启动不做匿名推导 |
| L002 | 同一 Net 内所有 Port 的介质必须一致                                   | 失败     | 暖通基本物理约束                                            |
| L003 | 每个 Port 的连接数不得超过其声明的上限（未声明时默认 1）              | 失败     | SDL 核心模型 · Port                                         |
| L004 | Connection 两端的 Port 类型与公称口径必须兼容                         | 失败     | 接口兼容性                                                  |
| L005 | 每个 Instance 必须引用存在的 Component 定义，实例参数必须在声明范围内 | 失败     | SDL 核心模型 · Instance                                     |
| L006 | 状态为"已确认"的参数才可被评价器当作已知输入                          | 失败     | 方法论书 2.4：不得用默认值消除缺口                          |
| L007 | 每个参与出图的设备必须有唯一显示标识                                  | 失败     | 原理图投影的唯一性                                          |
| L008 | Placement 引用的 Instance 必须属于同一 Layout                         | 失败     | SDL 核心模型 · 所有权与不变量                               |
| L009 | 换热设备的两侧介质不得直接混接（冷媒/冷冻水/冷却水）                  | 失败     | 暖通领域约束                                                |
| L010 | 设备参数缺失但被评价器需要时，应报"无法判断"而非"通过"                | 无法判断 | 六态语义                                                    |

## 设计约束

1. **第三态必须存在。** 缺少信息不是失败，也不是通过；把它当通过是最危险的静默错误。
2. **规则不修改模型。** 检查器只报告，不自动修复；修复属于编辑操作，需人确认。
3. **消息必须可操作。** 每条失败给出对象身份、字段、期望与实际的差异。
4. **规则本身要可测。** 每条规则至少一个正例与一个反例，随规则一起提交。
