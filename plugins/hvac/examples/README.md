## 真实项目切片目标：三层冷站 + 四层冷却塔

依据本地图纸集 `refs/hvac/cold-station-20261031/`（暖施-00~07），范围限定为：

- 冷源：离心式冷水机组 + 冷冻／冷却水泵 + 冷却塔；
- 环路：冷冻水供回水、冷却水供回水；
- 空间：机房粗布置（设备相对位置），冷却塔位于四层屋面；
- 环境：机房散热 → 温升 → 结露风险；
- 不包含：末端详细建模、控制逻辑、施工细节。
