# 简易求解器（solver）

近似计算，用于产生**带适用条件的证据**，不追求高保真仿真。

## 范围

| 能力 | 输入 | 输出 | 误差口径 | 失效条件 |
|---|---|---|---|---|
| 环路流量分配 | 环路拓扑、管径、设备阻力 | 各支路流量近似 | 待定（需与设计值对比标定） | 环路复杂或含未建模调节阀时 |
| 机房温升 | 设备散热、换气量、房间体积 | 稳态空气温度 | 待定 | 存在强局部热源或非稳态时 |
| 结露判据 | 空气温湿度、表面温度 | 结露风险等级 | 判据本身为阈值判断，非连续量 | 表面温度估计不准时 |

## 输出契约

每次求解必须输出证据包，不允许只返回一个数：

```
输入摘要     ← 用到的参数及其状态（已确认／未确认）
模型版本     ← 求解器版本 + 关键假设
适用性判断   ← 是否满足适用范围
结果         ← 数值 + 单位
状态         ← 通过／失败／无法判断
误差与假设   ← 误差量级、已知偏差来源
```

## 约束

1. **不返回裸数值。** 没有适用性判断的结果不可用于设计决策。
2. **越界报"无法判断"。** 输入超出适用范围时不得外推后再给结论。
3. **不确定性显式。** 结露这类阈值判断必须给出与阈值的安全余量。
4. **不做瞬态、不做时序。** 调度与时序属运行期（[ADR-0002](../../../docs/adr/0002-design-time-vs-operation-time.md)）。
