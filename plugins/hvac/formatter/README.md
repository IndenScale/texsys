# 输出格式

把模型投影成可交付物。**投影是单向的**：图由模型生成，图面不得成为第二事实源（见 [SDL 核心模型 · 原理图](../../../spec/sdl/01-core-model.md#原理图)）。

## 产物

| 产物           | 来源                 | 备注                                                       |
| -------------- | -------------------- | ---------------------------------------------------------- |
| 系统图／原理图 | 组成＋拓扑／另加行为 | 已由独立 `hvac-diagram` 包实现；空间标注与逻辑承诺分别降级 |
| 主要设备表     | 部件定义与实例 | 按类型分组，按身份稳定排序                                 |
| 设计说明片段   | 规则与依据           | 只生成可追溯到模型的部分                                   |

## 输出约定

1. **幂等**：同一模型两次生成结果必须一致，否则差异审查失效。
2. **稳定排序**：按身份而非插入顺序排列，避免无关变更干扰差异审查。
3. **文本优先**：能用文本表达的产物用文本表达，便于版本比较；二进制格式仅用于交付。
4. **单位显式**：所有数值带单位，不依赖表头约定。
5. **不写客户信息**：产物中不含客户名称、内部地址、人员信息。
6. **标注单列**：人工注记与自动生成内容分区存放，重新生成不覆盖人工区（[ADR-0017](../../../docs/adr/0017-schematic-projection-symbol-resolution-and-rendering.md)）。

## 当前状态

`hvac-formatter` 保持负责输入格式化、设备表和连接 JSON。`hvac:system-schematic` 由独立 `hvac-diagram` 包实现，组合通用绘图与 ELK 适配器，输出 SVG、非压缩 draw.io、绘图 JSON 和检查报告。首版范围见 [ADR-0019](../../../docs/adr/0019-first-executable-hvac-schematic-slice.md)，字段、降级与验收见 [构建契约](../../../spec/build/03-system-schematic.md)。设计说明片段仍为规划，不计作已实现产物。
