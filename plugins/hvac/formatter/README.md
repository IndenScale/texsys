# 输出格式（formatter）

把模型投影成可交付物。**投影是单向的**：图由模型生成，图面不得成为第二事实源（见 [SDL 核心模型 · 原理图](../../../spec/sdl/01-core-model.md#原理图)）。

## 产物

| 产物         | 来源                 | 备注                                                                      |
| ------------ | -------------------- | ------------------------------------------------------------------------- |
| 系统原理图   | Netlist + Layout     | 缺 Placement 时降级为纯连接图（[OQ-13](../../../docs/open-questions.md)） |
| 主要设备表   | Component + Instance | 按类型分组，按身份稳定排序                                                |
| 设计说明片段 | 规则与依据           | 只生成可追溯到模型的部分                                                  |

## 输出约定

1. **幂等**：同一模型两次生成结果必须一致，否则差异审查失效。
2. **稳定排序**：按身份而非插入顺序排列，避免无关变更污染 diff。
3. **文本优先**：能用文本表达的产物用文本表达，便于版本比较；二进制格式仅用于交付。
4. **单位显式**：所有数值带单位，不依赖表头约定。
5. **不写客户信息**：产物中不含客户名称、内部地址、人员信息。
6. **标注单列**：人工注记与自动生成内容分区存放，重新生成不覆盖人工区（[OQ-11](../../../docs/open-questions.md)）。
